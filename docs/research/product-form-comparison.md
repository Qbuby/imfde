# 情报产品形态对照 · 结论与对 imfde 的约束

> 合并 `traditional-intel-companies.md` 与 `fde-vertical-players.md`，供两份验收标准引用。2026-11-11。
> 本报告只汇总实抓页面能支撑的结论；未取得正文的机构（Gartner、The Information、S&P、Bloomberg、DIGITIMES、Agentic Daily tracker）不参与对照。

## 1. 四种商业模式，不要混着抄

| 模式 | 卖什么 | 付费切点 | imfde 能否照搬 |
|---|---|---|---|
| **数据终端 / 数据集**（CB Insights、S&P、Bloomberg、PitchBook） | 可检索筛选导出的结构化事实 | 订阅平台 / 席位 / API 与集成 | **否**：没有 10M+ 公司覆盖与终端工程 |
| **研究订阅 + 评级**（Forrester、Gartner、EIU、DIGITIMES） | 判断、框架、预测、公开方法论 | 全库检索 + 报告/框架 + 分析师访问 + 企业集成；Talk To Sales | **部分**：学固定内容类型词表、方法论公开、按角色组织；不学评级象限与机构销售 |
| **判断型通讯**（Stratechery、The Information） | 少数人的解释与洞察 | Plus / 会员论坛（具体切点未取得） | **是**：这是 imfde 的本体 |
| **专家网络 / 撮合**（Gartner 分析师访问、FDE Hub 对接、FDE Agency） | 人的背书、供需匹配 | 咨询 / 撮合 / 月订阅 | **否**：会把情报本体拖成咨询或招聘 |

**关键事实：没有一家把「公开新闻摘要」锁起来收费。** 免费层给事实、数据或单篇洞察；付费层给功能（检索、框架、方法论、专家、定制 briefing），或干脆靠 B 端变现（FDE Hub 内容全免费，靠招聘推广位/报告赞助/撮合）。

## 2. 展示与解释：市场共同做法

| 做法 | 谁在做 | 我们标准里的对应 |
|---|---|---|
| 数字旁紧邻标来源与时间窗 | FDE Hub 四个指标（Indeed 2025.4–2026.4 等） | D4 / R3 |
| 样本量直接显示 | FDE Pulse `$185K n=216 disclosed`、Perspective `1,500 / 154 companies / Feb–Apr 2026` | D4（v1.1 强化） |
| 「我们替你读完」作为价值主张 | FDE Pulse `We read 1261+ postings so you don't have to` | 本体定义的信息劳动代劳 |
| TL;DR / 主判断前置 + 承诺解释 | Perspective TL;DR；CB Insights 报告标题 `... Here's what happened.` | C1 / L1 独立成篇 |
| 独立 methodology 段 | Perspective Survey methodology | R1 / C3 |
| 评级绑定方法论 | Forrester Wave `trusted evaluation methodology` | R3 / 禁编分数 |
| 固定内容类型词表 | Forrester Predictions / Forecasts / Landscapes / Wave / Guides | 规范 §2 版式分区 |
| 按读者角色组织相关性 | EIU（Financial / Corporates / Academic / Government）、Forrester Who We Serve | C12 / 不越 R8 |
| 把可信度做成可核查产品事实 | CB Insights `Double-verified, continually refreshed` | C4 / 来源评级可见化 |
| 正文回指旧判断 | Stratechery `affirms my initial analysis` | 连续性最低形态（规范 §10） |

## 3. FDE 垂直玩家：谁没做什么

| 玩家 | 已有 | 明确没有 |
|---|---|---|
| FDE Hub | 中文百科 6 篇、自检、报告换邮箱、周刊、撮合 | 判断台账、证据等级、跨期核对、来源评级 |
| FDE Pulse | 1261+ 岗位、薪资、每周 Brief、雇主侧入口 | 判断台账、兑现记录 |
| FDE ジョブ | 506 岗位（本国 97）、每日更新、10 问导流 | 内容付费、判断 |
| Perspective AI | 1500 人调查、TL;DR、methodology | 跨期核对；且结论利好自己品类（→ R10） |
| 社区/培训/人才 | 社群、课程、订阅制人才 | 情报加工 |

**判断台账、来源评级可见化、口径三件套、改判留痕、独立立场披露——五件事全行业空缺。**

## 4. 不能照搬清单

1. 数据终端级密度与覆盖率（CB Insights 10M+ 公司）。
2. 评级象限 / 打分卡（需要可验证样本量与公开方法论，否则违反 R3/R7）。
3. 机构席位销售与「Talk To Sales」模式（无品牌与分析师网络）。
4. 知识库 + 撮合双市场（FDE Hub；需要供需两端运营）。
5. 常驻营销指标当首屏（FDE Hub 的 +729%/42×/$174K/50+，→ P9）。
6. 把「Double-verified」「权威」「深度」当形容词用，没有真做核验就是虚假宣传。

## 5. 差异化结论

imfde 可占的一格：

> **独立、有来源批判、有跨期兑现记录的判断型情报。**
> 不靠数据规模、专家网络或撮合。每期少量判断；每个判断带来源等级、口径、替代解释、下期核对指标；下期逐条核对并留改判记录。

付费切点按功能：免费给本期判断与事件档案；付费给跨期台账 / 全库检索 / 来源快照 / 方法论页（四选三）。**连续 3 期「内容 A + 展示通过」前不设付费入口**——这是两份标准的硬约束，不是建议。
