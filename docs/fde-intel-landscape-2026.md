## 二、谁在做 FDE 情报，各自怎么做、怎么变现

### 1. FDE Hub（fdehub.cc）— 中文知识库 + 周刊，最直接的同类
- **内容**：入门百科 6 篇（定义/区别/薪资/技能地图/Palantir 模式/中国变体）、洞察专栏（行业解读·案例拆解·海外编译）、行业雷达、数据报告（留邮箱取 PDF）、能力自检（3 分钟 13 维度）、企业↔人才对接、每周一封邮件周刊。
- **首屏逻辑**：主张（"搞懂 FDE，搞懂 AI 如何真正落地"）→ 4 个数据指标制造紧迫感 → 邮箱订阅。
- **变现**：招聘方推广位、报告赞助、对接撮合服务。站内内容全免费，**没有 C 端付费产品**。
- **对 imfde 的意义**：这是最像的对手，且它的内容深度远不如我们（我们是 559 个可核对案例，它是 6 篇百科 + 若干编译）。

### 2. FDE Pulse（fdepulse.com）— 岗位数据站
- 追踪 50+ 公司、1,300+ 在招岗位；中位 base ~$181K；每周一 "FDE Brief"（新增岗位/薪资变动/谁在招）。
- 内容层：What is FDE / How to become / Levels / New grads / Forward Deployed AI Engineer；50+ 真实面试题、简历指南、面试流程拆解。
- **变现**：岗位板（推测含 featured 位，未公开价目）。
- **对 imfde 的意义**：证明"岗位数据 + 周刊"是能起量的入口，且它的数据我们已经在每天自动采集。

### 3. FDE Jobs（fde-jobs.jp）— 日本垂类岗位板
- 506 个 FDE 垂类岗位，分 FDE / Solution Engineer / AI Implementation Engineer / Customer Engineer；18 篇知识文章（薪资基准、在招公司）。
- **变现**：Featured jobs 置顶（导流到企业招聘页）。

### 4. FDE.community（NYC）— 线下社群
- 私域社区，靠活动 + 精选岗位 + 同行引荐。**变现**：企业赞助活动/合作。

### 5. FDE Agency（fde.agency）— 人才市场，用订阅制打掉猎头费
- 用 AI 模拟筛选 FDE，**按月订阅收费，明确"不收 20–30%  placements 费"**，30 天替换保证。
- **意义**：这是对传统猎头模式的定价攻击，侧面说明这块毛利极高。

### 6. FDE 训练营（现金流最快的一类）
| 项目 | 价格/收费方式 |
|---|---|
| AI FDE School（US，8 周/100h） | **$3,900** 首期 → 计划 $5,220 |

### 7. Perspective AI — 用调研报告做 SaaS 的内容营销
- 发《State of FDE 2026》（n=1,500），拿到大量媒体引用，但**报告本身不卖钱**，是为它的"AI 访谈调研 SaaS"做漏斗。
- **教训**：数据报告的价值在于被引用，不在于直接卖。

## 三、变现模式的横向对照（含非 FDE 的成熟情报生意）

| 模式 | 代表 | 关键数字 |
|---|---|---|
| C 端/小 B 会员订阅 | 企查查 | 毛利率 **87–91%**，净利率 **44.8%**，**90%+ 收入来自会员**，1.5 亿注册用户 |
| 高价席位订阅（B2B 情报） | S&P Capital IQ Pro | **£55,000/用户/年**，36 万活跃用户；集团订阅收入 $7.9B |
| 媒体订阅 + 参赛/活动 | Cannes Lions / WARC | 续约率 **>95%**，订阅占集团 15%（£30.2m），WARC 单产品 £23m |
| 垂类 B2B 订阅转型 | Aspermont（矿业） | **订阅占营收 66%**，连续 37 季增长 |
| 华语产业情报年费 | DIGITIMES | 年费订阅，**续约率近 90%**，中高阶决策者 >70% |
| 分层计费 | 拓尔思 | 数据按调用量/账号数；知识产品按库+年订阅+RAG 调用；研判按份/周期/项目 |
| 周刊赞助 | 开发者垂类 | CPM **$25–80/千订阅**（开发者 $30–80，AI/LLM 更高）；精选岗位位约标准位的 **2–4 倍** |

**四条可复用结论**：
1. 毛利天花板由"数据是否自有、可复用"决定（企查查 88–90% vs 纯项目制公司营收腰斩）。
2. **订阅收入占 60–70% 是健康分水岭**（Aspermont 66%、企查查 90%）。
3. **续约率 90% 是 B2B 情报生命线**（WARC 95%、DIGITIMES 90%、Morningstar 93%）——低于此值获客成本收不回。
4. 定价必然分层：个人低价 → 团队席位 → 企业 API → 定制咨询（LIONS 与拓尔思结构一致）。

## 四、imfde 现在的问题（用我们自己的数据说话）

| 资产 | 数量 | 现状 |
|---|---|---|
| 世界动态事件 | 700 | 30 天窗内 **64/75 是招聘帖**，只有 1 条公司动作、7 条客户故事 |
| 可核对案例 | **559** | 埋在二级页面；**508 条有量化实测结果**，542 条有业务问题 |
| 中文原文 | 510 | 案例页有，但没有检索入口 |
| 题库 | 682 | 完全没露出 |
| 方法课 | 30 | 藏在 /方法 下 |
| 数据源 | 89 | 全自动每天跑 |

**诊断**：
1. **首屏没有一句话说清"这是什么、对我有什么用"**——现在靠 3D 沙盘 + 图例，第一次来的人必须先学会看，成本太高。
2. **最有价值的资产（559 个案例 / 508 个量化结果）不在首屏**，而最没价值的资产（单条招聘帖）占满了沙盘。
3. **零留资点**：全站没有邮箱入口，来的流量全部流失。
4. **零变现路径**：没有付费点，没有 BD 入口，没有报告下载页。
5. **没有"下一动作"**：看完一条事件，除了关掉没有别的事可做。

## 五、建议：两步走（先 A 拿流量，再 B 拿钱）

### 第一步（2 周）— 把首页改成 FDE Pulse 式的入口页
- 首屏三行字说清：`中国 FDE 情报站 / 1,300+ 在招岗位 · 559 个可核对部署案例 · 每周一更新`
- 三个 CTA：**免费订阅周刊**（邮箱，唯一留资点）｜**浏览岗位**｜**查案例库**
- 内容层：岗位板（已有数据）、案例库检索（industry/vendor/scenario/结果量化）、怎么转 FDE（30 节课 + 682 题）
- 3D 沙盘降级为「探索式鸟瞰 →」入口，不占首屏
- 变现起点：精选岗位位、报告赞助、企业对接表单

### 第二步（4–6 周）— 上 B 端部署情报订阅
- 数据资产：559 案例 × 20+ 字段（业务问题/现有流程/卡点/集成/评测/实测结果/失败迭代/产品化/FDE 角色），这是**没人有的一层深度**
- 产品：按行业/厂商/场景检索 + 每个案例的"可核对出处 + 中文原文"
- 定价参考：S&P 席位制（£55K/席）太高、企查查会员（几百元）太低；建议 **团队席位 ¥2,000–5,000/席/年 + 企业库 ¥2–5 万/年 + 季度报告 ¥3–8 千/份**
- 交付：季度《中国企业 AI 部署盘点》（行业×厂商×场景×结果），先免费发一期拿引用，再卖年度席位

### 不做什么（明确排除）
- 不做通用 AI 新闻（打不过 36氪/机器之心）
- 不做纯 3D 可视化 demo（好看但不解决问题）
- 不做社区/论坛（用户量不够，冷启动必死）
- 不做 FDE 训练营交付（需要你本人投入交付，与"情报站"定位冲突；可做导流分成）

**把 559 个案例做成可检索的"部署情报库"，首屏放检索框。**
