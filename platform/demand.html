设备巡检 AI 报告工具（私有化部署）

预算 ¥30,000 – 50,000 难度 A 要求 L2 · 3 人 交付周期 4 周 3 人报名 · 方案中 上架于 2026-08-28

需求背景

企业真实业务需求，已按平台规范脱敏发布

华南某离散制造企业（已脱敏，代称 M 厂），两条产线共 120 台关键设备，巡检员 8 人。现状：纸质表单 + 手机拍照零散存于个人微信，月度报告靠人工汇总，异常发现平均滞后 3 天。

期望：巡检员用手机记录设备状态，系统自动生成结构化巡检报告与异常预警；数据留在厂内，可对接现有 MES 系统，支持离线巡检。

为什么脱敏：企业名、产线参数、MES 字段名以代称发布，认领并签署 NDA 后开放完整需求包（含现场照片样例、MES 接口文档）。

验收标准（逐条量化，认领即锁定）

按平台规则，验收标准在立项时锁定，中途不得单方面调整 —— 保护双方
编号验收标准验证方式
A1拍照 + 语音备注自动生成结构化巡检报告（设备 / 部位 / 状态 / 照片 / 维护建议），单份生成 ≤ 60 秒现场实测 20 份，抽查合格率 ≥ 90%
A2识别 3 类预设异常（渗漏 / 异响 / 温升）并推送责任人，误报率 ≤ 10%标注测试集 200 条回放
A3MES 对接：读取设备台账与工单字段，字段映射可配置，无需改 MES 侧代码联调环境出验收单
A4离线可用：无网环境完成巡检并本地暂存，恢复网络后自动同步，不丢数据断网实测 + 数据完整性核对
A5三级权限（巡检员 / 主管 / 管理员），操作日志保留 ≥ 180 天后台演示 + 日志抽样

数据与合规边界

  • 数据不出域：模型私有化部署于厂内 GPU 服务器（企业已备 2×4090），禁止任何外网推理调用
  • 分层开源约定：通用报告引擎开源（协议认领时从 MIT / Apache-2.0 / AGPL 三选一锁定）；MES 连接器等场景定制层商业授权给企业
  • 现场约束：交付期累计驻场 ≤ 5 人日，其余远程；进厂需提前 3 天报备

交付物清单

  • 可运行系统 1 套（含部署脚本与回滚方案）
  • 开源内核仓库 1 个（通用报告引擎，含 README 与快速上手）
  • 运维手册 + 巡检员使用手册各 1 份
  • 验收演示 1 场（对照 A1–A5 逐条验证）
