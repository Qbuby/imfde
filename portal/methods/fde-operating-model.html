驻场团队怎么挂、听谁的

学习目标：Atlassian 页上能读到网关、路由、AI 负责人，没有人放哪的图。人放哪决定听谁的、赢了归谁。没有的汇报线不要补。

这一步怎么做

  1. 只写页上有的结构

    Atlassian 页上能读的是：AI 模型网关、主路由、热替换，以及 AI 负责人主导信任标准与路由策略；客户自服务。网关 / 路由 / 负责人可以进简报。人放哪的图、虚线实线、向销售还是向工程汇报，页上没有就留空。不要虚构汇报线、人数或头衔。

  2. 写清听谁的、赢了归谁

    人放哪，决定听谁的、赢了归谁。汇报线按主要使命选，但要用共同目标和决策权把销售、产品、工程连起来。页上：各团队自建评估、按质量 / 成本选模型；路由策略由 AI 负责人定。把「谁定标准、谁认生产结果」写上，不要补一张人放哪的图。

  3. 用生产结果防止变成高级售前

    防止变成高级售前，要有生产结果、代码质量、上线指标和现场学习回流，而不是只把演示做完。页上能抄的生产面：网关路由、厂商退役模型时换新版、团队自建评估。500 万+ agent 只当规模陈述。库里 72 写持续驻场，同样没有 FDE 头衔，也不能当成组队样本。

  4. 自主权有边界；路线冲突要有决策人

    自主权在风险预算、承诺权限、平台标准和升级门槛处结束。没有边界会漂，每件事都要高管批会停。页上有的边界：管理员控制包与网络访问；Rovo Max 在需要 Instagram 账号时由人提供。不要发明风险预算数字。现场和核心产品抢路线时，由明确产品决策人按统一证据框架权衡跨客户价值和战略。页上点名的是 AI 负责人，不要另编决策委员会。

  5. 交一页：人放哪、听谁的

    能读到的结构、人放哪、听谁的、赢了归谁、售前化防线、自主权边界，写在一页上。没有的汇报线和 FDE 头衔留空。

抄到自己的笔记里填。

客户 / 现场：
页上能读到的结构（网关 / 路由 / 负责人；页上没讲人放哪就空着）：
主要使命（听谁的）：
赢了归谁（生产结果谁认）：
共同目标与决策权（销售 / 产品 / 工程怎么连；页上没有就写「未知」）：
如何避免变成高级售前（生产结果 / 代码质量 / 上线指标 / 现场学习回流）：
自主权边界（风险预算 / 承诺权限 / 平台标准 / 升级门槛；页上没有数字就空着）：
路线冲突时的产品决策人与证据框架：
页上规模陈述（只抄、不当人数 KPI）：
明确不编的汇报线 / FDE 头衔：
明确不做：

  • 及格

    只写了网关 / 路由 / 负责人等页上结构；听谁的、赢了归谁能检查；有生产结果和回流，而不是演示；自主权有边界，路线冲突有决策人和证据框架。

  • 不及格

    编了人放哪的图或 FDE 头衔；用规模陈述当人数 KPI；只做演示没有生产回流；或让合同最大的客户决定路线。

  • 不要编的数

    不要发明汇报线、人数、SLA 或 FDE 头衔。500 万+ agent、350,000+ 客户、20+ 产品是规模陈述；「成本降、质量升、延迟优」不当人数验收公式。
