方案范围

学习目标：先锋领航 700 人一次切不开，页上是先放狂热者小组去证明。对着这页把第一刀写死：切哪条、数据谁能碰、试点怎么验收。范围没切开，不是模型不够强。

这一步怎么做

  1. 切开第一刀薄垂直切片

    先锋领航 700 人一次切不开，页上是先放狂热者小组去证明。这一刀对着能切开的那条工作流写：真实集成、能检查的验收，不是无集成的界面原型。

  2. 写死约束、数据权限和试点验收

    页上点名的是品牌指南和顾问-客户偏好。进入试点前先写：谁能碰、人工复核、回退、试点怎么验收。不要假定上线后再补权限。

  3. 稳定规则用确定性，模型只管非结构化

    一封邮件 37 步、16 次交接里，能写成规则的交接不要交给模型去猜。模型管草稿和解释；可审计的步骤用确定性逻辑。不要藏起来等交付再补责任。

  4. 高风险输出先当草稿

    顾问-客户偏好进了个性化，输出还没法保证时，第一版限定为草稿，写明谁批准、何时升级。降温度、页脚免责或加长上下文，都不能代替批准闸门。

  5. 交一页范围简报

    约束、权限、验收、第一刀、明确不做，写在一页上。37 步 / 16 次交接用来看从哪切开，不是验收 KPI。狂热者小组「两天对三周」是页上的证明点，不要扩成全组织已达成的周期承诺。

看一个例子

先锋领航 / Writer

先锋领航页上是一封邮件 37 步、16 次交接，700 人一次切不开。75 人桌面安装是虚荣指标：工具在桌面上不等于工作已改变。简报只写页上有的场面，不要补金额或头衔。

经营问题
停止铺 1990 年代营销牛径（一封邮件 37 步和 16 次人工交接），并用 agent 重建工作流。
旧流程
2018 年营销技术「技术堆」。早期 Writer 铺开按桌面衡量：75 人有它，但 Kelton 白天听不到它——写作助手，不是工作流。700 人组织太大，无法一次转型。
卡点
桌面上的工具 != 工作已改变。在 700 人上追求完美会卡住进度。
人在环内
找到狂热者（约小组，不是 700）。CMO 被告知自己进产品。顾问对个性化资产作出反应。

基线地图（步骤 / 交接，不当 KPI）：
虚荣指标（不要当成做成）：

  • 及格

    约束、数据权限、验收和第一刀切片都写死；切片含真实集成；稳定规则与模型分工清楚；高风险有草稿 / 批准 / 升级路径。

  • 不及格

    一次铺全组织、只有无集成原型、资格规则全交给模型、用桌面安装数当做成，或验收不可检查。

  • 不要编的数

    37 步 / 16 次交接不是 KPI；75 人桌面安装是虚荣指标；「两天对三周」只写狂热者小组、页上有的口径。不要补金额、FDE 头衔或上线后百分比。
