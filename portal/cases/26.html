Garner Health 借助 Augment Code 加速结果驱动的护理

Garner Health 面对严格的 HIPAA 要求，以及不断增长、日益复杂的数据分析平台，工程团队选择了 Augment Code。他们用它更快地搭建复杂基础设施原型，在全组织范围内执行编码标准，同时让开发者留在自己喜欢的 IDE 里，且不影响合规。

Garner Health 处理数十亿条医疗理赔记录，根据真实患者结果给医生排名，把更多护理送到全国表现最好的医生手里，扭转医疗成本上升、质量下降的趋势。这个使命带来了繁重的站点可靠性工程（SRE）工作：

24×7 运行的复杂 ETL 管道。

快速增长的团队：年初 40 人，年底超过 100 人。

雄心勃勃的基础设施想法（动态资源调配、状态漂移检测），大到无法在空闲时间里做原型。

“人脑能同时记住的东西有限，”站点可靠性工程师 Forrest Thomas 说，“系统太大时，你无法同时抓住所有变动部分。”

Garner Health 评估了 GitHub Copilot、Cursor、Windsurf 等几款 AI 编程工具。Augment Code 在几项技术指标上胜出：

速度与质量：亚秒级补全，更高保真度的代码。Forrest 说：“Cursor 感觉迟钝，Augment 的回复在我思路还在流动时就到了。”

安全与合规：客户代码可选不训练、客户托管密钥、Okta SSO。“HIPAA 合规是硬门槛，Augment 通过了。”

代码库感知：全项目索引和 MCP 集成，提供架构上下文。“它真正理解了我们的 Go 和 Python 仓库。”

IDE 灵活性：JetBrains、VS Code、Vim 的轻量扩展。“我们不用强迫开发者放弃自己习惯的工具。”

转折点是一个周末的 POC：Augment 为 Forrest 的动态调配项目生成了约 10 K 行可直接上生产的 Go 代码——这个项目他已经拖了好几年。

“Augment 从根本上改变了我们开发软件的方式，”Forrest 总结道，“它已经变得不可或缺，不仅提升了生产力，还改善了系统的整体质量和设计。”

Garner Health 采用 Augment 后获得了明显的技术优势：

加速开发：开发者能快速从想法进入功能原型，大幅提升团队创新能力。“Augment 让你迅速从构思进入编码心流，”Forrest 解释，“我不用纠结‘该用 for 循环还是 map’这类语言细节，它让我把注意力放在更大的问题上。”

更高代码标准：Augment 精准的编码辅助减少了人工干预，即使在团队快速扩张时也能保持质量。

可扩展实践：Augment 帮助扩大后的团队保持一致的编码标准，简化了 onboarding 和协作。Forrest 强调：“借助 Augment 的指南和 MCP 集成，我们可以在组织层面协调编码标准。”

无缝上线：60 名开发者两天内全部接入，正面反馈且零 IDE 切换。

“Augment 终于让我专注于设计优雅的系统，而不是纠结导入和样板代码。我再也无法想象没有它的编程生活。”——Forrest Thomas，Garner Health 站点可靠性工程师

这是一款面向专业软件工程的工具，而不是“氛围编程”。

“如果你只想按 Tab，就会交付大量自己都不理解的代码，”Forrest 警告。这种“氛围编程”能快速出代码，但之后团队要调试脆弱、不透明的系统。他说：“用 Augment，我从想法直接进入心流。它把整个系统放在上下文中，我就能专注于架构和结果。”

Forrest 不再与导入或语法搏斗，而是把专业能力用在设计可扩展、可维护的服务上。

简而言之：氛围编程只是自动化按键；Augment 自动化了繁琐工作，让工程师真正做软件工程——深入思考系统应该如何以及为何这样构建。
