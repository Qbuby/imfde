Intercom 借助 Augment Code 扩展多 agent 工程工作流

Intercom 选择 Augment 而非其他工具

Intercom 发布速度很快。它是领先的 AI 客户服务公司，推出 Fin——表现最佳的客户服务 AI Agent，以及新一代人工支持帮助台。他们的基础设施和产品团队管理大型 Ruby 和 JavaScript 代码库、分布式系统，以及源源不断的高影响力变更。

但当高级工程师探索 agent 驱动开发时，他们发现现有工具在上下文、一致性和可靠性上都力不从心。尝试过 Cursor 和多种 LLM 编码工具后，Intercom 采用了 Augment Code，以支持并行 agent 工作流，加速大型功能构建，并让工程师有可靠的方式卸载重复的编码细节，同时不牺牲质量。

Intercom 的复杂系统

Intercom 工程师处理复杂系统，准确性至关重要，包括：

大型相互关联的 Ruby 代码库

需要精确、多文件编辑的基础设施变更

快速发布文化和高技术标准

团队工作流和工具偏好的高差异性

对于 Intercom 的高级产品工程师 Marvin Bitterlich 来说，早期的 AI 编码工具不够可靠：“它们会幻觉、忘记文件，或者直接跑偏。在 agent 工作流出现之前，我根本不用 AI——然后一切都变了。”

要让 agent 实用，Intercom 最需要的是可靠的上下文管理。

为什么选择 Augment Code？

此前，Marvin 先评估了 Cursor 的 agent 模式——立刻遇到了限制。忘记文件、计划不一致、上下文处理差，让真正的工程工作流无法进行。Augment 因其稳定性和上下文保真度立即脱颖而出。

需求 Augment 优势 Marvin 的看法

上下文准确性 大型代码库的深度理解 “它就是知道东西在哪里。我自然说话——Augment 就能找到正确的文件。”

一致的任务执行 Sequential Thinking + 稳定的 agent 计划 “其他工具会失去跟踪。Augment 真的能完成工作。”

可扩展的 agent 工作流 本地 + 远程 agent，支持 GitHub Issue/PR 集成 “我每周跨协调的 agent 运行数百个 PR。”

大型系统上手 准确的摘要 + 图表生成 “我自己读的代码少多了——Augment 可靠地串联起各个点。”

工作流灵活性 支持 VS Code、JetBrains、CLI “我在 VS Code 和 CLI 工作流之间切换，Augment 在两者中都运行良好。”

转折点：Augment 在小型原型和大型功能构建上都成功了，而其他工具失败了。“如果我必须在 Claude Code 中工作，我仍然总是安装 Augment Context Engine MCP。”

Marvin Bitterlich
Senior Product Engineer

结果：在规模上并行 agent 开发

Marvin 使用 Augment 的本地和远程 agent 来编排复杂的多 PR 工作流：

规划功能

拆分成 GitHub issue

启动远程 agent 并行生成草稿 PR

审查并合并

让 Augment 协调合并后的工作

“我们构建了一个大型内部应用——超过 100,000 行代码。我一周合并了 200 个 PR。Augment 完成了任务，我审查了每一行。”

高质量代码，一致交付

过去几个月，Marvin 90–95% 的生产代码由 Augment 编写——质量标准与他为自己设定的相同。“这是我会写的代码。只是我不用自己敲。”

更快上手不熟悉的系统

Augment 总结不熟悉的服务，追踪依赖关系，并为团队讨论生成 mermaid 图表。工程师只需阅读关键文件——Augment 处理其余部分。

更专注的工程时间

通过卸载细节工作，Marvin 疲劳更少，生产力更高：“我可以在周末项目上工作 12–14 小时，因为 Augment 处理了耗尽精力的部分。我只需审查和指导。”

Intercom 工程师现在在样板代码上浪费的专注时间更少，更多时间用于解决实际问题。

面向经验丰富的工程师的工具，而非氛围编码

Marvin 指出 Augment 在“氛围编码”失败的地方成功：“你仍然需要理解问题。我在脑子里解决它——Augment 处理实现。”

Marvin 的建议：

清晰地描述问题（就像和同事说话）

给出高层次意图，而不是长提示

只要求 AI 做可能且理解透彻的任务

使用 agent 做可并行的工作；使用聊天做精确编辑

结果：真正的工程加速，而非捷径驱动的混乱。

VS Code、JetBrains、CLI；GitHub Issue/PR；在 Claude Code 中工作时也使用 Augment Context Engine MCP。
