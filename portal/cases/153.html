公司自己讲的数字 · 比较可靠

Code for America 用对话式支持，带着共情出现在申请人面前

Code for America 是非营利，做一套数字工具，帮人在美国申请福利。目标是数字时代里民有、民治、民享的政府。首席传播与市场官 Arlene Corbin Lewis 说，各级政府都该为所有人好好转；他们用真人洞察拆障碍、改政府。跟地方政府一起，让公共项目更好进。加州 GetCalFresh、明尼苏达 MNBenefits 都是他们做的。

GetCalFresh 帮加州居民申请 CalFresh（该州 SNAP）。2019 年起帮 600 多万人拿到或保住 SNAP。新冠前 Intercom Messenger 每周大约 3,000 次对话；疫情高峰每周 9,000，涨了 300%。靠 Inbox 和机器人，量暴涨还能做个人化支持。Resolution Bot 用英语、西班牙语、粤语给即时自助、答常见问题，紧急的仍快速交给人。明尼苏达申请福利时间缩短 80%；经 MNbenefits 处理 25k 份申请。
