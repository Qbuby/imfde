NVIDIA 工程师和研究人员怎样用 Codex 构建

团队用 Codex 配 GPT-5.5 交付生产系统，把研究想法变成可跑的实验。页上结果：端到端研究工作流速度提升 10x；40k 名 NVIDIA 员工能用上 Codex。

在 NVIDIA，工程师把 Codex 当复杂工程的默认工具，也用来跑端到端机器学习实验。Codex 建在 GPT-5.5 上，生产跑在 NVIDIA GB200 和 GB300 基础设施上，能撑更长、更自主的会话——不只执行，还会浮出原 prompt 里没有的问题和想法。

Senior Software Engineer Dennis Hannusch：「Codex 是我们复杂工程任务的首选工具，有了 GPT-5.5，它能浮出其他模型找不到的程序 bug 和缺口。」「我个人觉得 Codex 配 GPT-5.5 自主得多，少很多手把手。」他已经用 Codex 把一个内部平台从 MVP 做成可上生产的系统。团队还用 Codex 几小时内做出类似 Riverside 的内部播客录制应用。Hannusch：「考虑到隐私约束，采购软件本来要几周。」用带电脑交互的 Codex 桌面应用，系统在构建时自己测了视频和音频录制。「我什么都没做——完全自主构建和测试。」「Codex 彻底改了什么东西值得去建的门槛。」

对研究团队，Codex 大体自动化了研究闭环：找研究方向、写机器学习实验脚本、在远程机器上跑。AI researcher Shaunak Joshi：「光跑实验就 10x 速度提升，因为它能扛整条端到端机器学习研究工作流。」「GPT-5.5 作为创意搭档是巨大解锁，尤其在知识工作上。」团队把模型指向强化学习等领域的大量论文。Joshi：「GPT-5.5 看起来比竞品更有创意。它帮我沿整条链追踪证据片段，还建议一张想法知识图。」Codex 应用支持 SSH，他不用再操心远程主机登录和配置。Joshi：「如果你有一份性能不行的旧代码库，Codex 很擅长机器翻译。很多人把 Python 仓库交给 GPT-5.5，它改写成 Rust，效率像 20X。」Hannusch：「我们才刚摸到它能做什么的表面。」

给负责人

要解决什么
复杂、多仓库工程，加上手工端到端机器学习研究循环（找方向、写脚本、跑实验）。
结果
跑端到端 ML 研究工作流速度提升 10 倍；40,000 名 NVIDIA 人可使用 Codex；Python→Rust 重写使代码效率约 20 倍；一个内部播客应用在数小时内完全自动构建并测试。
接了哪些系统
带计算机交互的 Codex 桌面应用（构建时测试视频/音频）；到远程主机的 SSH 支持；在 NVIDIA GB200/GB300 上生产运行
用了什么数据
大量相关论文语料（例如强化学习）；机器学习基础设施
人还管哪一步
工程师审阅拟议变更；系统在长会话中仍以顶尖准确度表现
多久上线
内部播客录制应用在数小时内拉起（采购本要数周）

给现场的人

主要用在哪
把内部平台从 MVP 做到可上生产；经 Codex 桌面应用的计算机交互在数小时内拉起内部播客应用；把端到端 ML 研究工作流自动跑起来。
以前怎么干
手工研究循环和手工采购软件（例如一个播客应用要花数周采购）。
卡在哪
漫长、多步的研究/工程；很难在长会话里把上下文留住。
用了什么模型
Codex（GPT-5.5）
事情怎么流转
一个研究 agent 把模型指向论文语料，编写 ML 实验脚本并在远程机器上运行；把 Python 仓库机器翻译成 Rust（效率约 20 倍）
怎么上线
Codex 在 NVIDIA GB200/GB300 基础设施上生产使用
能不能复用到下一家
