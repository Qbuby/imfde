Qualtrics 用 Cody 加快单元测试创建和理解代码

Qualtrics 是全球体验管理（XM）公司，建造世界上最好的品牌用来交付出色前线体验、建高绩效团队、设计人们热爱的产品的软件。Qualtrics 服务超过 19,000 个客户，工程团队超过 1,000 名软件开发者。开发者体验（DevX）团队负责向那些开发者交付方案和过程，改善他们日常的快乐和生产力。DevX 也跑项目来提高 Qualtrics 的工程质量杠。

生成式 AI 和 ChatGPT 在 2023 年迅速走红时，Qualtrics 的 DevX 团队立刻看见在开发团队内用 AI 的潜力。团队把评估 AI 编码助手当成 2023 年夏的主要举措。Sr. Manager、Qualtrics DevX 团队负责人 Godwin Babu 假设 AI 使用能显著改善工程团队内的生产力。

Qualtrics 在决定 Cody 之前评估了市场上若干 AI 方案，安全是主要优先级。Godwin：「选编码助手时，我们优先 DLP [数据防泄漏] 和对我们知识产权安全的保证。Cody 跟我们已经在位的系统无缝工作。」Qualtrics 的安全协议延伸到他们的代码托管，这是他们跑自己的自托管 GitLab 实例的原因。Cody 与所有主要代码托管工作，无论自托管还是基于云，所以能插进 Qualtrics 现有设置。Godwin：「我们在自己的数据中心里跑自己的 GitLab 实例，Sourcegraph 跟它无缝工作。这让签 Cody 变得容易。」DevX 团队也想要支持最新 LLM 的方案，好让团队总能访问最快、最准的模型。这把 Qualtrics 带回到 Cody，它支持若干 LLM 作为选项。「Cody 切换后端的能力，从 Claude 到 GPT，对我们很有吸引力。这是快速移动的领域，我们不断看见 LLM 更新，所以有一个能对新技术 LLM 快速反应的工具对我们重要。」最后，Qualtrics 已经是 Sourcegraph 客户，工程团队广泛使用 Code Search。质量工程经理 Gordon Fu 说，Qualtrics 对 Sourcegraph 作为供应商的现有信任和信心，让 Cody 很快冒到 AI 评估的顶部。Qualtrics 最终基于安全、LLM 互操作、以及与现有代码托管设置工作的能力，决定用 Cody 作为 AI 编码方案。

自从把 Cody 带到工程组织，Qualtrics 工程师报告用 Cody 时离开 IDE 去网上找信息少 28%，理解代码快 25%。他们调查的多数工程师也报告每天用 Cody 省 10 到 30 分钟，DevX 团队估计大约是开发时间的 10%。往前看，Godwin 也看见 Cody 会在工程团队里驱动甚至更多进展的地方：「我们在想用 Cody 的地方之一是把它跟其他举措接上。例如，在 DevX，我们有一个项目提高代码覆盖：给所有团队设目标，用单元测试达到特定覆盖。我们在这里看见与 Cody 的直接相关，因为 Cody 被证明擅长创建测试和提高代码覆盖。」

Qualtrics 高级软件工程师 Brendan Doyle 已经看见用 Cody 写单元测试的价值。Brendan 在一个为 AWS Lambda 和其他内部基础设施即代码（IaC）服务建包装库的团队上干活。「对开发者不是秘密：写单元测试是开发者日常为写可靠软件的必要时间坑，」Brendan。「生成单元测试，到目前为止，是我最喜欢的 Cody 功能和省时点。我可以把脑力花在别处，而不是花在琢磨怎么写测试上。」「本来要我多个开发日的东西，用 Cody 一小时做完。Cody 能生成测试模板，然后我可以 prompt 它做调整，让测试正好覆盖我在找的。」Brendan 的团队也从用 Cody 上手大型代码库和现有项目拿到价值，尤其对更年轻的工程师。「作为初级工程师最令人生畏的事之一是在大型、现有代码库上干活。关于那份代码总有大量领域知识限于写它的人，无论文档写得多好。总有只有代码作者知道的细微差别。但如果开发者知道怎么 prompt Cody，Cody 能找到上下文并给他们解释代码。」

给负责人

要解决什么
DevX 想要能提高 1,000+ 开发者生产力与质量的 AI 编码协助，同时不破坏 DLP / IP 安全或其自托管 GitLab。
结果
工程师报告有 Cody 时离开 IDE 去浏览网页少 28%；理解代码 / 回答问题快 25%。多数受访工程师报告每天节省 10–30 分钟（按 DevX 约 10% 的开发时间）。页上主角：单元测试一整天 → 大约 10 分钟。Brendan：多个开发日 → 一小时。
接了哪些系统
Cody 对着 Qualtrics 数据中心里的自托管 GitLab。既有 Code Search。
用了什么数据
自托管 GitLab 代码库；内部 IaC / AWS Lambda 包装库。
人还管哪一步
工程师提示 Cody 调整生成的测试。初级人员仍需知道如何提示。
多久上线
英雄：过去要一整天的单元测试现在大约 10 分钟。Brendan Doyle：本要多个开发日的工作在一小时内完成。

给现场的人

主要用在哪
单元测试生成（Brendan Doyle，AWS Lambda / IaC 包装库）；初级人员在大型既有代码库上的 IDE 内代码理解。
以前怎么干
已是 Sourcegraph Code Search 客户。2023 年夏由 Godwin Babu（DevX 高级经理）领导的 AI 助手评估。
卡在哪
安全/DLP 与 IP 保护是主要过滤器。需要最新大模型切换，以及自己数据中心里的自托管 GitLab。
用了什么模型
Cody，可切换后端「从 Claude 到 GPT」（页上措辞）。无单个钉死模型。
怎么验收
工程师调查：离开 IDE 的比率、代码理解速度、每天节省分钟。DevX 估计约 10% 的开发时间。
怎么上线
Cody 带到工程组织（1,000+ 开发者）。DevX 也计划把 Cody 接到单元测试覆盖计划。
能不能复用到下一家
前瞻（不是结果）：把 Cody 接到组织单元测试覆盖目标。
本要花我多个开发日的事情，用 Cody 一小时就完成了。——Brendan Doyle，Qualtrics Senior Software Engineer

备注

Sourcegraph 官方案例（抓取 2026-08-29）。具名 Godwin Babu、Gordon Fu、Brendan Doyle。28% / 25% / 10–30 分钟/天是受访工程师报告；约 10% 是 DevX 估计。英雄「一整天 → 约 10 分钟」与 Brendan「多个开发日 → 一小时」都在页上——不合成一个数字。19,000 客户与 1,000+ 工程师是公司规模，不是 Cody 结果。
