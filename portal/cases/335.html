OluKai 如何用 Sierra 规模化 Aloha 体验

OluKai 营销 VP Melissa Ziegler。2005 年创立，OluKai 作为唯一为挑剔、活跃消费者打造生活方式和鞋履的夏威夷启发品牌脱颖而出。OluKai 创造了高端皮革凉鞋这个品类，此后把产品目录拓宽到创新、多用途的男女鞋履阵列。公司持续增长在开始战略转向直接面向消费者（DTC）分销时加速。这次转移，用强电商存在补充稳健的批发运营，旨在创造镜像品牌核心价值的数字客户体验：Aloha、Ohana、和不妥协的质量。2020 年后，DTC 通道激增，驱动公司收入的显著部分。目前 OluKai 正转成动态全渠道品牌，经批发、实体和电商（自有通道和 Amazon）增长。

随着线上生意增长，公司做出强承诺：确保与客户的每次数字互动都出色。这导向 Aloha Experience 的创建：端到端客户旅程，确保每次接触——无论经广告、社交媒体、网页、邮件还是电话——都对齐 OluKai 经 Aloha 连接世界的愿景。为让 Aloha Experience 成真，OluKai 把客服团队带进营销组织，归 Melissa Ziegler 管，并把这些服务团队成员改名为 Day Makers。Day Makers 做的不只是回应服务问询；他们旨在建长久关系，并在每次互动中创造愉悦体验。无论是替换被狗咬的凉鞋还是回应独特客户需要，每次互动都是加深与客户连接的机会。CMO Kerry Konrady：「你很小的时候，做真实很容易。增长同时保持真实，是品牌面对的最大挑战。」

在 OluKai，客户服务问询经电话、邮件和社交媒体进来。公司继续增长时，量的增加让维持目标响应时间变难。Aloha Experience 团队主管 John Elkins 指出：「75% 的请求是常见问题，如丢件或退货请求。我们试着加个人触感，但会变得单调。」Melissa 想把 Aloha Experience 团队的焦点从处理重复任务转到增强客户忠诚。「我们一直鼓励团队花时间、理解客户。如果客户有一件人生大事，我要你用合适程度的热情去接那个人。」像许多服务团队一样，Aloha Experience 团队已经把常见客户问询的应用内回复标准化。OluKai 实施过并很快下线了聊天机器人，发现它们缺速度或效力。Melissa：「聊天机器人挫败我们的客户多于帮助。直接邮件互动被证明更让人满意。」公司规模化快过以往，是时候试新东西。

Melissa、John 和整个 Aloha Experience 团队走进 AI 领域，用 Sierra 开发 OluKai 的第一个 AI agent。agent 能把 LLM 自然语言处理和推理的力量用到 OluKai 的客户服务上，用让 OluKai 独特的信息、政策、品牌和文化。Melissa 对 AI 能力谨慎乐观：「AI 大概能读我们的政策，但它会理解怎样以及何时做例外吗？给出那份个人触感？」上线后结果惊人。「观察 AI agent 共情地回应客户，镜像我们人工坐席的做法，令人震惊，」Melissa 回忆。John 补充：「AI 显著减少了我们团队在重复任务上的工作量，让我们能盯更有影响的客户互动。」「AI 接过例行问题后，我们的 Day Makers 能集中在更复杂的案子。这帮我们创造愉悦时刻，也让我们的工作更有回报、更好玩。」

更聪明、更高兴的退货。OluKai 给客户提供多种退货选项，包括提供预付运单或环保、成本有效的 Happy Returns 服务。但许多客户不熟悉 Happy Returns。OluKai 的 AI agent 努力及时教育客户关于 Happy Returns 并建议最近地点。不像人工坐席需要手工搜这信息，AI agent 理顺过程，对客户更快、对员工更不累赘。运营 VP Derek Bradley：「Sierra 能解释 Happy Return 的价值并即时分享附近地点，创造更好的消费者体验，同时帮我们用更高效的退货省成本。」AI agent 也擅长理解微妙和细微差别。例如，OluKai 有 30 天退货政策，但他们愿意做例外。Melissa：「晚 5 或 6 天是灰色地带。一般来说，我们批准退货并就未来购买教育客户政策。」AI agent 有效采用这份灵活做法，「调和我们写明的规则和政策与灰色地带例外。」

为评估客户对 OluKai AI agent 的反应，Aloha Experience 团队跟踪每次对话的客户评分并在表现仪表盘上监控。Sierra 目前交付大约 4.5 / 5 的客户满意度。「我们预期很高，目标是 4.75，」Melissa 分享。「我们觉得改善个性化、鼓励 AI 交付愉悦时刻会让我们到那里。」OluKai 也跟踪平均处理时间和平均响应时间。Aloha Experience 团队成员通常在 2 到 48 小时内回应客户问询，取决于时段有多忙。「反过来，AI 是即时的，你的首次响应时间和总平均处理时间降到几乎为零，」Melissa 说。「而且，如果你是像我这样凌晨 2 点才想起来的消费者，我可以从 AI agent 拿到 24/7/365 的回复。」最后，OluKai 衡量 AI Agent 的解决率。大约 70% 的时间 OluKai AI Agent 能在没有人介入的情况下解决一张工单或问询。「清楚理解解决率让我能在我们把资源投到哪之间做决定。」例如，转向 AI 调整了 Aloha Experience 团队（AXT）的目标。John Elkins：「以前我们的焦点是每天关掉 150 张工单。有了 Sierra，我们降低了工单量预期，让团队能用共情和照料集中在更复杂的案子。」

给负责人

要解决什么
2020 年后 DTC 激增时把 Aloha/Ohana 服务（电话、邮件、社交）铺开，而不让 Day Makers 淹没在丢件/退货工单里——先前聊天机器人已被关掉。
结果
Sierra 交付约 4.5/5 的 CSAT（团队目标 4.75）。约 70% 的时间智能体在无人介入下解决工单/问询。Sierra 现在处理 OluKai 70% 的服务工单。首次响应 / 平均处理时间降到几乎为零，对照人工 2–48 小时。
接了哪些系统
Sierra agent 做服务；运营/营销/Day Makers 塑造行为；对话评分仪表盘。
用了什么数据
政策、品牌/文化、Happy Returns 位置；计划 CDP 个性化。
人还管哪一步
Day Makers 集中于复杂取悦；关单目标从聚焦 150 单/天下调。
怎么交给客户
Melissa Ziegler，营销副总裁；Kerry Konrady，CMO；John Elkins，Aloha Experience Team 主管；Derek Bradley，运营副总裁；Dan Kaparski，数字产品总监。

给现场的人

主要用在哪
OluKai AI 智能体：订单/退货旅程、Happy Returns 位置、灰色地带退货例外，全年无休。
以前怎么干
营销内的 Aloha Experience Team（Day Makers）；应用内罐头回复；聊天机器人上线后很快被关掉。
卡在哪
75% 的请求是常见的（丢件、退货）且单调；人工首次响应视忙碌为 2–48 小时；30 天退货政策有灰色地带例外。
用了什么模型
使用 OluKai 政策、品牌与文化的 Sierra LLM agent。
事情怎么流转
先常见工单；解释 Happy Returns + 最近位置；批准约晚 5–6 天的退货并教育；立即首次响应。
怎么验收
对话 CSAT（约 4.5/5，目标 4.75）；AHT/首次响应；无人介入的解决（约 70%）。
怎么上线
服务工单；探索主动延误消息、CDP 个性化、弃购/产品推荐。
失败了怎么改
先前聊天机器人给客户的挫败多于帮助；在 Sierra 之前直接邮件更让人满意。
能不能复用到下一家
主动外联、CDP 个性化、收入协助（产品信息、弃购）在考虑中。
聊天机器人给客户的挫败多于帮助。观察 AI agent 共情地回复客户、镜像我们人工坐席的做法，令人震惊。——Melissa Ziegler，OluKai 营销副总裁
