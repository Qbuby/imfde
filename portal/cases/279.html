Model ML 用 GPT-5.6 Sol 把金融活的最后一公里做完

2026 年 8 月 10 日。创业公司 Model ML 用 GPT-5.6 Sol 做能编辑的 PowerPoint 和 Excel。相对 Fable 5，每个幻灯片 deck 少 21% token；专业就绪率比 Opus 5 高 16.6 个百分点；相对 Opus 5，每个 Excel 工作簿少 36% token；定制 tearsheet 从大约一小时降到 5 分钟。

金融分析要过最后一公里：对证据、建文件、排格式、核每个数、把每条主张链到出处。成品还得能编辑、经得起审。联合创始人、兄弟 Arnie 和 Chaz Englander 两次成功退出后，经家族办公室投资，顺手给自己做软件。长出来的 agent 帮金融专业人士从需求走到研究、分析、成品 deck 或工作簿。核心 agent 做计划、选工具、对证据、跑计算，每一步送到最合适的模型，常常是 GPT-5.6 Sol。自家文档工具生成带可追溯出处的原生 PowerPoint 和 Excel。CEO Chaz Englander 说，更早的模型能干分析师的活，但用户得把任务拆清楚、把输出长什么样说死；有了 GPT-5.6 Sol，agent 离最终输出近得多。

产品他们叫 surface-agnostic：邮件或 Model ML 应用里开工，Microsoft Office 插件里接着干，不用再解释一遍。投委会 deck 能从 brief 和材料变成可编辑 PPT；Excel 可以从客户模板或空白簿开始，收数、跨多表建公式和逻辑，再套金融格式。Composite（公司给金融服务 AI 的评测）里，Excel 工作流 GPT-5.6 Sol 每个工作簿比 Opus 5 少 36% token。一家全球资产管理人，定制 tearsheet 分析师大约一小时，现在大约五分钟。另一条工作流一次过完虚拟资料室，超过 100,000 行、几百个文件。

PowerPoint 评测覆盖几百份生成的 deck。GPT-5.6 Sol 100% 测例交出 PPT，Opus 5 是 76%；过专业就绪门（能不能拿去实质审查）43.3%，对 26.7%。Deck 质量、brief 遵循、层级、一致性也领先 Opus 5。Chaz 说，用户该盯判断：改假设、磨信息，而不是把分析重做一遍。

给负责人

要解决什么
金融工作的「最后一英里」——对证据、把文件搭好并排版、核对每个数字、把每项主张链到来源——要求很高；做完的幻灯片或工作簿必须可编辑，还要经得起审查。
结果
GPT-5.6 Sol 每本工作簿比 Opus 5 少用 36% token，每套幻灯片比 Fable 5 少用约 21% token；在一家全球资产管理公司，一名分析师约 1 小时组装的定制 tearsheet 约 5 分钟完成；含 100,000+ 行和数百个文件的虚拟数据室一次处理完；PowerPoint 可交付性 43.3% vs 26.7%（Opus 5），产出幻灯片 100% vs 76%。
接了哪些系统
Model ML 自己的文档工具创建带可追溯来源的原生 PowerPoint/Excel；一套 agent harness 加载数据集成、文档编辑和代码执行工具包
用了什么数据
一份 brief 外加源材料；客户模板；含 100,000+ 行和数百个文件的虚拟数据室
人还管哪一步
金融专业人员在分享工作前检查假设、来源和信息
怎么交给客户
Model ML 通过与 OpenAI 的现场会议达到这一设置，追踪 agent 如何规划演示、选择工具并保持语境，然后精炼指令并决定每个工具包何时加载。

给现场的人

主要用在哪
一个核心智能体把金融任务从最初请求带到研究、分析和完成的幻灯片或工作簿：规划、选工具、对证据、跑计算，每一步分给最合适的模型。
以前怎么干
一名分析师组装一份定制 tearsheet 大约一小时。
卡在哪
手工、耗时且易错的格式化和核对。
用了什么模型
GPT-5.6 Sol（API）
事情怎么流转
一个核心 agent 规划工作、选择工具、核对证据并运行计算，把步骤路由到最佳模型（常常是 GPT-5.6 Sol）；在 Model ML 的 Composite 基准上评估
怎么验收
Model ML 的 Composite eval：产出 PowerPoint 幻灯片 100%（对比 Opus 5 的 76%），专业就绪关口 43.3%（对比 Opus 5 的 26.7%），每套幻灯片 110 万 token（比 Fable 5 少约 21%）；Excel 每本工作簿 token 比 Opus 5 少 36%；一家全球资产管理公司的 tearsheet 1 小时→5 分钟；一个 100,000+ 行的虚拟数据室一次处理完
能不能复用到下一家
在生产中扩展 GPT-5.6 Sol，包括此前由 Opus 4.8 处理的工作流
「更早的模型能做分析师的工作，但用户必须清楚地拆解任务，具体说明希望输出长什么样。有了 GPT-5.6 Sol，我们发现 agent 更接近最终输出。」——Chaz Englander，Co-founder and CEO at Model ML
