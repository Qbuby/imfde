Clariti：两分钟出高管级补丁合规报告，并发现「幽灵访问」

Clariti IT Operations Manager Colin John 用 Rippling AI 把数小时手工合规变成一条 prompt，并在 100+ 个已连接应用里浮出一个安全缺口。页上数字：2 分钟跑周补丁合规报告；一条 prompt 审计 100+ 应用的幽灵访问。公司 150 人，总部加拿大，服务北美政府客户的云软件公司。

环境是 Windows 和 Mac OS 混合终端，跨多个部门，补丁行为、合规率和风险画像不同。跟踪补丁状态并翻译成高管能读的东西，要在 Rippling 多个工具里拉，再对照 Microsoft Office 和 Adobe 等应用源。每周同一套手工：从 Rippling 出原始报告，按 OS 类型和版本过滤，下钻部门，找出落后的团队和个人，对照应用级补丁数据，再组装成高管能读能行动的格式。从头到尾要几个小时，每周无例外。月度访问审计是另一种形态：员工换岗或离职后，跟踪 100 多个已连接应用里访问是否完全收回，是多日工作。

Colin 用一条综合 prompt 替换整条手工报告工作流：为所有终端生成高管级补丁合规报告，含总体合规百分比、按合规状态拆终端、按严重度（critical/high/medium）做风险分类、找出合规最低的部门和团队、过去 90 天补丁表现趋势；输出简洁、非技术、适高管，并含潜在业务影响和改进建议。回来的是完整高管就绪报告：标题级总体合规和终端摘要、可直接贴进邮件或幻灯的表格拆解、各严重度终端数、按部门和设备类型落后情况、90 天趋势、给领导立即关注的优先前五风险清单、分层行动计划（第一周立即、两周内短期、30 天内中期）。Word 和表格格式可下载。以前数小时，现在三分钟内，只剩 Colin 自己核准确。

继续探索时他发现第二个没在找的问题。一名换岗用户让他查完整访问概览——发现一个已从 Rippling 下板的员工在 Atlassian 里还有活跃账户。100 多个已连接应用里，即使下板流程管得好，API 边角或不完整集成也可能留下残余访问。Rippling AI 一条 prompt 浮出来；以前每月要三个完整工作日去查的那种异常。Colin：「安全归根结底仍是每个人的所有权。但管安全会让事情好办——尤其有 Rippling AI。」
