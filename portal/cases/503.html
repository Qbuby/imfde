用毛利率换护城河：为什么前线部署工程师是创业公司最热岗位

事实证明，把 Salesforce 拉下马，不像拉起一个接了 OpenAI 的语音 agent 那么简单。公司想用轻量、像包装纸一样的接入，去换掉遗留记录系统把持的核心工作流，agent 太容易断或直接失败。吊诡的是，销售、支持和法律里，复杂 AI 产品正在爆炸式增长。啃复杂工作流的企业软件公司，常常在头两年就把 ARR 从 $0 做到 $5 million、$10 million，或超过 $20 million。那新 AI 创业公司怎么解这些缠人的用例？买 AI 的企业像你奶奶拿到 iPhone：他们想用，可要你来装。PLG 执念对上……

给负责人

要解决什么
要让 AI 客服 agent 能自主处理范围很广的客户支持请求，产品本身不足以交付，需要有人帮客户把 agent 立起来
结果
文中仅定性描述：使 Decagon 的 agent 能自主解决范围广泛的支持请求
人还管哪一步
Decagon 保留供人类监控、调整、分析 agent 工作的产品工作流，并在需要时提供升级到人工客服的机制（出自同站另一篇，见后条）
驻场怎么写的
Decagon 有一支规模可观、名为 Agent Product Managers 的人工团队，成员相对技术化，与客户紧密合作把 AI 支持 agent 立起来，负责实施、集成与排障

给现场的人

主要用在哪
AI 客服 agent 自主分流与解决支持工单
该公司有一支规模可观的人工「Agent Product Managers」团队，与客户紧密合作把 AI 支持智能体立起来。这些 PM 相对技术化，帮助实施、集成与排障，好让 Decagon 的智能体能自主解决范围广泛的客户支持请求。
