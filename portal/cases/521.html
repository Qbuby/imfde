中文全文还在写入。下面两栏是已经拆过的字段。

给负责人

要解决什么
企业客户依赖一张 API 有限、彼此不通的复杂业务系统网；AI 公司必须深度接入这些定制系统才能产生价值
接了哪些系统
把集成作为一等工程投入来做，使产品嵌入客户核心运营工作流，难以被拔出而不影响其他系统
用了什么数据
客户内部业务系统数据（传真件、TMS 数据、企业工具数据）

给现场的人

主要用在哪
Tennr：接入长尾的传真与遗留医疗系统，打通医疗机构之间的患者转诊前流程；HappyRobot：接入客户自建 TMS，部署 AI 语音 agent 处理货运电话业务；Glean：价值来自与核心企业工具的关键集成
以前怎么干
医疗场景中大量依赖传真与遗留医疗系统；物流场景依赖自建的 TMS（运输管理系统）与人工货运电话
卡在哪
遗留系统 API 有限、系统之间不互通
事情怎么流转
HappyRobot 的 AI 语音 agent 承担货运电话操作
能不能复用到下一家
深度垂直集成被定位为护城河手段之一（与成为 system of record、工作流锁定、客户关系深耕并列）
例如在医疗领域，Tennr 大力投入接入长尾的遗留传真与医疗系统，以理顺各医疗机构之间的患者转诊前流程。在物流领域，HappyRobot 接入客户自建 TMS（运输管理系统）平台，部署其 AI 语音智能体处理货运电话业务。
