公司自己讲的数字 · 比较可靠

KPMG 怎样用 AI 和 WRITER 加快上市、让人能上手

KPMG 的 aIQ 转型项目用 WRITER 提高生产力、增强创造力，更快给客户交付价值。数千小时腾出来去做更高吞吐、更高价值的活。KPMG 终端用户对 WRITER 的满意度高。衍生内容创作省时 60-80%。总部美国。行业：专业服务。部门：营销、企业传播。AI Agents：研究助理、衍生营销内容、活动包、网红营销、LinkedIn 帖、会议纪要、博客、新闻稿。影响：上市速度、省时。KPMG LLP（KPMG US）是全球领先的专业服务公司之一。

给负责人

要解决什么
让思想领导力与营销先上市，而不把整天花在衍生资产或研究拉取上。
结果
数月内节省数千小时（页上）。衍生内容创建节省时间 60-80%（英雄 + Maral 估计）。研究助手：一整天拉取到一小时。「指数级 ROI」是页面语言，不是算出的倍数。
接了哪些系统
业务用户创建的 Writer agent。研究助手中的实时网页搜索。
用了什么数据
网页搜索加上内部 KPMG 文档/研究；思想领导力与网络广播内容。
人还管哪一步
每个团队的倡导者；每周办公时间；小组通话上的「你今天怎么用 AI？」；绩效评估中的 genAI。人仍拥有质量。
多久上线
研究示例：周三早间请求，一小时出稿对照一整天。
怎么交给客户
Writer 支持从实施到 agent 构建、持续支持与 beta 功能——未冠以 FDE。

给现场的人

主要用在哪
研究助手（财报电话、竞争对手、KPMG 研究）；思想领导力到衍生营销 agent；活动、社交、影响者、公关、recaps、博客、新闻稿。
以前怎么干
从长篇税务思想领导力手工做衍生营销（网页、社交、邮件、谈话要点）。出版物的研究拉取要「一整天」。
卡在哪
技能提升、量、重复内容，以及守住 KPMG 声音/质量。
用了什么模型
Writer agent（页上未点名单个 LLM）。
事情怎么流转
定制 agent 把思想领导力 / 一小时网络广播变成衍生包的初稿。
怎么验收
英雄：数千小时被重新利用；高用户满意度分数；衍生内容节省时间 60-80%。正文：研究拉取从一整天到一小时；Maral 估计衍生交付物 60-80%；数月内数千小时。
怎么上线
营销与企业传播。其他团队有兴趣。中央计划负责人 + 嵌入式倡导者。
失败了怎么改
没有 agent，每个人都必须是提示巫师。在场边等待会让竞争对手先动。
能不能复用到下一家
治理模型、倡导者、办公时间、社区、绩效指标中的 genAI。
这个 AI agent 是巨大的时间节省……我估计它为我们节省创建所有这些交付物所需时间的 60-80%。——Maral Devian，KPMG US 税务营销副总监

备注

Writer 官方案例（抓取 2026-08-29）。具名 Brian Demick、Maral Devian、Lauren Boyman。60-80% 是 Maral 对衍生包的估计。数千小时在页上但未描述方法。
