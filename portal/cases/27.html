MoneyGram 借助 Augment Code 加速创新、生产力和速度

MoneyGram 使用 Augment Code 的方式

MoneyGram 是一家全球领先的支付网络，正在进行一场转型，核心目标是快速、审慎且大规模地为全球客户提供无缝的全渠道体验。

MoneyGram 的架构和工程团队正在重新思考技术的构建和交付方式。通过与 Augment Code 的合作，MoneyGram 让团队能把想法从概念快速推向生产，同时保持 MoneyGram 品牌的可靠性和信任。

快速行动，审慎构建

MoneyGram 运营着全球最强大的金融科技平台之一，拥有庞大且多样的代码库，重点是用速度和精准度扩大创新。

通过把 Augment Code 集成到开发流程，团队正在现代化基础设施、提升系统可靠性，并在数百个项目中加速交付。

“我们的目标是创建一个开发环境，让更新、迁移和测试无缝进行。Augment 通过自动化繁重工作，帮助我们实现这一目标，让团队能专注于为客户设计和创新。”

Ganesan Janarthanam
Platform Architect

以前需要在不同平台间切换上下文，现在集成让工程师能在系统和工具间流畅工作。

与 Confluence 和 Jira 等平台的深度连接，让开发者保持在流程中，消除不必要的上下文切换和手动文档工作。

“Augment 像一位领域专家坐在我身边，带我浏览源代码，”Jana 继续说，“以前我必须找到写代码的人让他们解释，现在 Augment 可以指导我，帮助我比以往更快地交付增强功能。”

为什么选择 Augment？

更快地用 AI 实现现代化

MoneyGram 用 Augment 自动化 Spring Boot 迁移，把项目时间从数周缩短到数小时。

“用 Augment，迁移大约需要两小时，”Jana 说，“我们只需告诉 Augment：执行迁移并确认完成——它就做到了。”

你的 AI 结对程序员

工程师现在用 Augment 进行实时代码解释、重构和新员工入职。

“就像身边有一位高级工程师。你可以问任意多问题——它从不疲倦。”

内置企业集成

Augment 原生集成 Atlassian Jira、Confluence 和其他支持的 Model Context Protocol (MCP) 服务器工具，让工程师无需离开 IDE 就能工作。

“我可以让 Augment 自动发布 Confluence 页面——它就做到了，”Jana 说，“这省去了大量手动文档工作。”

始终最新，始终连接

MoneyGram 对 Augment 快速采用新模型印象深刻。

“Anthropic 某天发布新 Claude 模型——第二天早上它已经在 Augment 中上线，”Jana 说，“这让我非常高兴。没有等待，没有延迟。”

Augment Code 与 MoneyGram 的集成

通过 Augment Code，MoneyGram 的工程师在整个软件生命周期中实现了生产力和质量的提升。

Spring Boot 升级时间从数周缩短到数小时

自动化生成的单元测试覆盖率超过内部目标

在 IDE 内自动创建最新的 Confluence 页面和 README.md 文件

结果
Spring Boot 升级从数周减到数小时（Jana：约两小时）。自动测试把单元测试覆盖提到超出内部目标（目标未公布）。从 IDE 创建 Confluence 页面和 README.md。单个工程师现在不到 5 周交付全栈应用。
接了哪些系统
IntelliJ、VS Code；原生 Atlassian Jira/Confluence 及其他 MCP 工具。
用了什么数据
MoneyGram 源代码；Jira；Confluence；MCP server。
人还管哪一步
Jana 将其描述为从不疲倦的高级工程师；人仍拥有设计。
多久上线

给现场的人

主要用在哪
自动 Spring Boot 迁移（大约两小时）。在 IDE 里发 Confluence。单个工程师做全栈应用。

1000+ 团队；数百个项目。IntelliJ 和 VS Code。
