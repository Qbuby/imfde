Fujitsu 与 Cohere 合作推出 Takane AI 模型

Fujitsu 与 Cohere 合作做出 Takane，一套面向受监管行业企业的先进日语 LLM。模型基于 Cohere 的 Command 系列定制，撑住高级企业能力，包括加快工作流、多语言理解、数据抽取和复杂推理。Takane 现已进入 Fujitsu 的数字化转型产品，帮日本企业提高效率、做更聪明的决定、给出更好的客户体验。

给负责人

要解决什么
受监管行业（金融/医疗/政府）需高精度日语 LLM，通用 LLM 在日语业务场景不准
结果
Takane 在 JGLUE 基准达世界领先分数；覆盖法律/金融/制造工作流，支持日/德/中/葡多语
接了哪些系统
Cohere Command 系列（私有部署）+ Fujitsu Kozuchi / DI PaaS
用了什么数据
日语行业语料、企业文档

给现场的人

主要用在哪
Takane——基于 Cohere Command 定制的日语 LLM，支持工作流加速、多语言、数据抽取、复杂推理
以前怎么干
依赖通用 LLM，日语复杂术语与合规场景受限
卡在哪
日语准确率低、合规与安全要求高
用了什么模型
Cohere Command 系列定制 → Takane（JGLUE 基准世界领先）
怎么上线
私有部署，纳入 Fujitsu 数字化转型产品（Kozuchi / DI PaaS）
我们致力于通过把最先进的 AI 推向市场来支持客户的业务转型……通过与 Cohere 这样的全球伙伴合作。——Yoshinami Takahashi，Fujitsu 企业副总裁、首席运营官
