Tubi 如何用 AI 按规模创造「神奇时刻」

免费流媒体平台 Tubi 把品牌建在民主化内容获取上。使命是让所有人获取世界上所有故事，迅速、准确的客户支持至关重要。但公司规模化到服务全球数百万观众时，客户体验团队面对熟悉挑战：在巨大规模上运营时，你怎么维持那份个人触感？Blake Bassett 和 James Jones 发现的答案，是把客户体验当成战略优势往里靠——强调把支持互动变成他们所谓的「神奇时刻」。产品 VP Blake Bassett：「我一直把客户支持不只看成运营支出，而看成增长引擎。你怎么超越事务性互动，给观众和生意都提供价值？」领导品牌 AI 举措、并与 Blake 紧密合作客户体验战略的 James Jones：「客户体验是 Tubi 品牌以及我们怎么与用户互动的关键部分。我们的应用上有很多不同用户，预期和需要不同。」

团队愿景有野心：把每次客户互动变成经迅速问题解决和个性化内容推荐、与客户建更深连接的机会。为把愿景做活，他们与 Sierra 合作。合作前，Tubi 的客户支持经传统邮件系统运营。James：「用户经我们的表单发消息，我们的客服坐席经邮件回复。非常老派的方法，尤其当人们习惯更偏消息的系统。」限制鲜明。响应时间拉到数小时。高峰观看时间——晚间、周末、重大体育赛事——造成做不到的人员挑战。James：「你怎么为一个小时把团队扩 10 倍？」决定现代化客户体验时，自建还是外买不轻易。Bassett：「我们是 AI 的早期采用者，内部建过 agentic 系统。」团队有技术能力自建——但他们认识到对的伙伴的价值。Bassett：「我们决定买而不是建，因为白手套入职和培训。我们觉得 Sierra 是值得押的那匹马，我们很满意——它兑现并交付了。」

实施聚焦两项直接对齐 Tubi 使命的核心能力：技术支持和个性化内容发现。Sierra 驱动的 agent 处理从排障流媒体问题到密码重置的一切，但真正体现 Tubi 愿景的是内容推荐能力。Blake：「我们相信创造所谓『神奇时刻』——真的人性交换，我们把热爱的东西分享给别人。Sierra 有意思的是能按大得多的规模、用我们的品牌声音做那件事，本质上经打我们目录的 API 端点推荐内容，并用我们对用户所知推荐会共鸣的东西。」agent 部署后，那些曾经棘手的人员挑战干脆消失——AI agent 吸收黄金时段和直播活动的需求峰值，无论周二下午 3 点还是超级碗第四节，都维持一致的服务质量。

上线三个月后，结果是转型性的——也令人惊讶。James：「我大概最紧张的是 CSAT 会下去。我曾假设人们真的想要人对人界面，把他们送到 AI 会把我们的 CSAT 拉下来。但我意识到人们要的是答案——他们要问题被解决。」数字讲故事：CSAT 增加七个百分点，containment 到 80%，解决时间从数小时或数天转到数分钟。也许最重要的是，agent 解放了人的团队去盯更高价值工作。James：「现在他们花更多时间给组织其余部分提供关于用户在说什么的洞察，这影响路线图，帮工程师更好理解该在哪处理技术债。」同时经合作，Tubi 的 CX 团队经历了心态转变——并同时把 AI 技能提了一级。James：「跟 AI 和客户体验团队一起工作时常常让人紧张——『这对我未来要做什么意味着什么？』但走过 [Sierra 面向客户的培训项目] Sierra University 后，我看见我们的客户体验团队被点燃，实际上自己动手构建来帮改进我们的 agent。」Bassett：「每次互动都是创造终身粉丝的机会。」

给负责人

要解决什么
在数百万观众规模上，穿过黄金时段和直播活动高峰，保持对人、带品牌语气的支持与内容推荐。
结果
上线后三个月：CSAT 上升七个百分点；拦截达到 80%；解决时间从数小时或数天变为数分钟。智能体吸收需求高峰（黄金时段、超级碗第四节）。
接了哪些系统
Sierra agent + 目录 API；吸收黄金时段/直播活动高峰。
用了什么数据
Tubi 目录 API；他们对用户的了解；支持表单/聊天。
人还管哪一步
人把更多时间花在向全组织输送洞察/路线图；CX 团队在 Sierra University 之后在 agent 上继续构建。
多久上线
结果报告于上线后三个月。
怎么交给客户
Blake Bassett，产品副总裁；James Jones，AI 与企业平台。

给现场的人

主要用在哪
智能体做流媒体排障、密码重置，以及用用户上下文 + 目录 API 做目录推荐。
以前怎么干
老派网页表单到邮件；响应时间以小时计；不可能为超级碗一小时流量把人员扩 10 倍。
卡在哪
自建还是外购：团队已有内部智能体系统，但需要一对一高规格入职/培训。
用了什么模型
Sierra AI agent。
事情怎么流转
排障 / 密码重置；以品牌语气从目录推荐内容。
怎么验收
CSAT 变化；拦截；解决时间。James Jones 曾假设 CSAT 会下降。
怎么上线
已上线；上线后三个月的结果。
失败了怎么改
假设人们要人对人、CSAT 会下降——被证伪。先前邮件表单「非常老派」。
能不能复用到下一家
CX 团队在 Sierra University 之后有动力在 agent 上继续构建；白手套入职（不是 FDE 职位头衔）。
我曾假设人们真的想要对人界面，把他们送到 AI 会把我们的 CSAT 拉下来。但我意识到人们要的是答案——他们要问题被解决。——James Jones，Tubi AI 与企业平台
