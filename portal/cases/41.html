Atomicwork — 使用 Cohere（Rerank + Command R+）的 Atom AI

Atomicwork 是一家 IT 服务管理公司，最近上线了 AI 数字助理 Atom AI，旨在通过自助服务方案提升现代企业的生产力和 IT 支持。

公司借助 Cohere 的 Command R+ 和 Rerank 模型，结合检索增强生成（RAG），打造出能显著提高 IT 支持团队效率的工具。

Atomicwork 遇到的难题是：客户难以把分散的业务应用和内部服务连起来，导致集成复杂、运营低效。IT 部门每天要处理大量请求，涉及企业信息、软件更新、应用开通和故障排查。

产品负责人 Aparna Chugh 说，这些重复任务占 IT 请求总量的 70%，消耗了 IT 团队 50% 的有效时间。

Atomicwork 的目标是把企业知识和搜索功能无缝嵌入员工日常使用的协作工具，简化 IT 管理、提升生产力。

公司从一开始就把提高答案质量、降低延迟放在首位。

Aparna Chugh 表示：“Cohere 团队是极好的设计伙伴，他们和我们紧密合作，分享最佳实践和指南，甚至帮我们针对具体用例调整提示词。”

AI 平台负责人 Shanthi Vardhan 此前就用自然语言处理做过方案。团队在企业产品方面经验丰富，但大语言模型对他们来说还很新。

他们注意到 Cohere 推出第三方 API 调用后，决定用 Command R+ 和 Rerank 开发 Atom AI。

方案包括几步：

把 SharePoint、Confluence 等企业数据源接入，实现全面检索，让员工在 Slack 和 Microsoft Teams 里就能直接搜索答案。

选用 Cohere 的模型，追求高准确率和低延迟。RAG 系统把回答建立在企业知识之上，保证信息可靠。

他们把检索机制改成用更少上下文，提高准确率。评估标准包括忠实度、相关性和上下文召回。

Rerank 开箱即用，轻松接入流水线。Cohere 团队帮忙调提示词，进一步提升准确率、降低延迟。

团队从 1 名 AI 科学家和 1 名开发者起步，现在已有 3 名 AI 科学家、2 名 AI 开发者，另外还有 2 名开发者专注 AI 平台。

用 Rerank 从 POC 到评估再到上线只花不到一周；用 Command R+ 部署额外用例只用了两周。

CEO Vijay Rayapati 说：“Atomicwork 数字职场体验方案的核心动力来自 Cohere 的企业 AI 平台，尤其是 Command R+ 模型。它无与伦比的准确性和可扩展性，加上 Cohere Rerank，让我们的数字助理 Atom AI 具备了交付真实成果所需的精度和性能。”

跑完评估基准后，Atomicwork 看到用 Cohere Rerank 准确率提升 20%。

使用 Cohere 模型后，方案在各项指标上表现良好：延迟降低 75%，准确率比 GPT3.5 等竞品模型高 168%。

Aparna Chugh 补充道：“Cohere 团队是极好的设计伙伴，他们和我们紧密合作，分享最佳实践和指南，甚至帮我们针对具体用例调整提示词。”

Atom AI 的上线正在改变客户的 IT 支持流程，提供准确、快速的答案，提升运营效率。
