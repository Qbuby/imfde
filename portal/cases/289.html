创业公司 Parloa 做出客户愿意交谈的服务 agent

Parloa 用 OpenAI 模型为企业模拟、评测和运行语音驱动的客户服务系统。

早期，联合创始人 Stefan Ostwald 在一家保险呼叫中心待了一天，听坐席一遍遍处理密码重置、保单问题和例行变更。他意识到大量工作可以自动化。柏林的 Parloa 开始做规则语音 agent，ChatGPT 出现后演进成现在的 AI Agent Management Platform（AMP），建在包括 GPT-5.4 在内的新一代模型上。AMP 让企业按自然语言定义行为、接到内部系统，用内置模拟和评测快速迭代，端到端跑从简单路由到复杂多步请求。Engineering Manager Ciaran O'Reilly Ibañez：「模型只有在生产里管用才重要。我们跟 OpenAI 紧密合作，让模型对实时对话够快、够可靠。」

AMP 面向业务用户和主题专家，不用写代码就能建 agent。O'Reilly：「有了 AMP，不同业务单元的主题专家真能以更瘦、更简单的方式建 agent 并接 API。」专家用自然语言设角色、指令、工具和边界。上线前用 GPT-5.4 这类模型模拟客户对话：一个模型当来电者，另一个跑配置好的 agent。同一批模型再用确定性检查和 LLM-as-a-judge 打分，看是否跟指令、是否正确用工具、是否完成任务。直播时编排层用 agent 配置和对话上下文 prompt OpenAI 模型生成回复、经 RAG 取信息、或触发工具打客户后端。对话后，单独的 OpenAI 工作流做摘要、意图分类、按规则评表现。agent 变复杂后，单一巨型 prompt 难维护，Parloa 引入模块化：认证、改预订、账户更新等拆成子 agent。关键步骤可用结构化 API 链和事件逻辑保证顺序。模拟还用 GPT-4.1、GPT-5-mini 等。

评测优先。Senior Applied Scientist Matthäus Deutsch：「新模型出来，我们就用基准套件对着跑。对我们很重要的是，不只在理论基准上能用，要在真实用例上能用。」测试量指令跟随可靠性、API 调用一致性、延迟和现实条件下的整体表现。只有在真实客户情景里可靠的模型才上生产。Deutsch：「企业客户面临真实迁移成本。系统在生产里跑起来，他们会保持稳定，只有收益清楚才换。」在数百万次客户交互里，多数对话无摩擦解决。一次部署中，一家全球旅行公司把要求转人工的请求降了 80%。

语音有另一套约束：语音转文字、模型推理、文字转语音的低延迟管线。延迟关键，模型层一点点停顿会叠成主叫听得见的停顿。Parloa 独立评测语音栈各块：语音转文字看词错误率，尤其保单号或账户标识这类敏感输入；文字转语音用盲听测试看自然度，再对真实客户交互核对；语音到语音模型正在评生产就绪，焦点是延迟、准确和成本。这些系统从一开始为全球部署而建，基准跨多种语言。

给负责人

要解决什么
企业需要规模化、一致且可靠的语音客户服务；僵化的意图树难维护，边缘场景会失败。
结果
在一次部署中，某全球旅行公司将人工座席请求减少了 80%。Parloa 的智能体处理零售、旅行和保险领域的数百万次对话，大多数无摩擦解决。
接了哪些系统
AMP 编排用 agent 配置 + 上下文 prompt OpenAI 模型生成回复，通过 RAG 检索或触发工具；确定性 API 链与基于事件的逻辑；模块化子 agent
用了什么数据
通过 API/RAG 接入内部系统；客户后端
人还管哪一步
人工座席处理升级；领域专家用自然语言定义行为与边界
怎么交给客户
Parloa 与 OpenAI 紧密合作，使模型足够快且可靠以支持实时语音对话，并持续在类生产环境中对新模型迭代做压力测试。

给现场的人

主要用在哪
AMP 让领域专家用自然语言定义智能体行为，仿真对话（一个模型扮演来电者，一个扮演智能体），用 LLM-as-judge + 确定性检查评估，然后端到端部署。
以前怎么干
基于规则的语音智能体；僵化的意图/流程映射。
卡在哪
单体 prompt 带来僵化和意外副作用；生产环境边缘场景失败。
用了什么模型
GPT-5.4, GPT-4.1, GPT-5-mini (API)
事情怎么流转
模块化子 agent（认证、预订、账户）；model-as-caller + model-as-agent 仿真；通过 LLM-as-judge 与确定性规则评估；随最新模型持续更新
怎么验收
仿真 + LLM-as-judge + 确定性检查；针对每个新模型运行的基准测试套件；speech-to-text 词错误率测试；text-to-speech 盲听测试；speech-to-speech 就绪评估
怎么上线
覆盖零售、旅行和保险的数百万客户对话
能不能复用到下一家
AMP；实时语音支持
