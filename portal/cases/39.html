Oracle — 与 Cohere 合作的 100+ GenAI 用例

Oracle 把 Cohere 的 Command R 和 Command R+ 模型集成到 Fusion Cloud Applications 里，把生成式 AI 直接放进客户的核心业务流程。

这些应用用 Cohere 的 Embed 和 Rerank 模型搭建了检索增强生成（RAG）系统，减少幻觉，给出更准确的回答。

集成支持 100 多个 GenAI 用例，帮助企业简化运营，同时保持企业级安全和隐私。

2023 年，Oracle 计划为全球企业开发强大的生成式 AI 服务。通过与 Cohere 合作，Oracle 希望 AI 集成能让客户自动化端到端业务流程、改善决策、提升客户体验。

从 Oracle Fusion Applications 入手，Oracle 想通过 14,000 多家客户的用户群把 AI 带进企业。

Oracle Fusion Applications 团队想在云应用里嵌入前沿 AI，给客户更多价值。难点是把 AI 无缝嵌入现有流程，同时保证数据隐私和安全，这是所有企业服务商最关心的。

Oracle 还想建一个灵活框架，让客户和合作伙伴能加入自己的生成式 AI 功能，满足特定行业和业务需求。

Oracle 与 Cohere 合作，把生成式 AI 功能带进 Oracle Fusion Applications。借助 Cohere 的前沿可扩展大语言模型 Command R 和 Command R+，Oracle 客户现在可以用上强大技术，提高生产力，快速完成任务。

企业因此能改善客户和员工体验，提升数据洞察准确度，创造更多业务价值。

Cohere 团队与 Oracle Fusion Applications 团队合作，在财务、供应链、人力资源、销售、市场营销和服务流程中嵌入 100 多个 GenAI 用例。

应用用检索增强生成（RAG）系统减少幻觉，并用 Cohere Embed 和 Cohere Rerank 优化搜索和检索，得到更准确的回答和更强的解决方案。

“Oracle 押注 LLM 厂商能持续给出更好、更智能的结果，我们与 Cohere 的合作证明了这一点。”

Miranda Nash
Oracle 应用开发与战略集团副总裁

这些 GenAI 用例建在 Oracle Cloud Infrastructure (OCI) 上，利用其领先的 AI 服务，旨在为业务用户日常工作提供功能，同时让客户牢牢掌控数据治理和安全，并定期获得改进和升级。

Miranda Nash 解释说：“Oracle 押注 LLM 厂商能持续给出更好、更智能的结果，我们与 Cohere 的合作证明了这一点。通过 Oracle Fusion Applications 的季度更新，客户可以轻松采用新的嵌入式 AI 功能，优化 AI 能力，提高财务、人力资源、供应链和客户体验流程的速度和准确性。”

Oracle Fusion Applications 中与 Cohere 模型集成的新生成式 AI 功能包括：

Oracle Fusion Cloud Enterprise Resource Planning (ERP)：

Insight Narratives：AI 识别异常、差异和偏差，提供可操作的解释，帮助做出更明智的决策。

Management Reporting Narratives：AI 帮助财务人员理解差异和趋势，提高报告效率。

Predictive Forecast Explanations：AI 为预测模型生成上下文，建立信任并促进更广泛采用。

Project Status Summaries：AI 生成执行摘要，提高项目透明度，减少手动报告。

Project Plan and Proposal Generation：AI 根据过去项目和最佳实践定制项目计划和提案，提高运营效率。

Oracle Fusion Cloud Supply Chain & Manufacturing (SCM)：

Item Description Generation：AI 创建标准化、SEO 优化的产品描述，节省时间，促进客户参与。

Supplier Recommendations：AI 根据产品和类别数据推荐供应商，帮助提高采购效率并降低成本。

Negotiation Summaries：AI 生成定制谈判摘要，加快审批和成交过程。

Oracle Fusion Cloud Human Capital Management (HCM)：

Job Category Landing Pages：AI 帮助构建定制职业网站着陆页，提高候选人参与度。

Candidate Assistant：AI 回答候选人的常见问题，让他们在招聘过程中保持知情和参与。

Manager Survey Generation：AI 让经理快速为团队生成调查，促进员工反馈和理解。

Oracle Fusion Cloud Customer Experience (CX)：

Service Webchat Summaries：AI 创建客户聊天会话摘要，帮助改善问题跟踪，减少代理的手动任务。

Assisted Authoring for Sales and Marketing：AI 生成客户成功故事和营销材料，提高生产力和活动表现。

通过将 Cohere AI 技术集成到 Oracle Fusion Applications 中，Oracle 帮助企业做出更明智的决策，提高运营效率，为员工和客户提供更个性化的体验。

这一合作展示了 Cohere 将 AI 无缝集成到企业软件的能力。我们很自豪能继续支持 Oracle 在云应用中利用生成式 AI 引领潮流。
