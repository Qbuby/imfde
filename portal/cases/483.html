Rippling · 软件科技

Rippling最大、最具战略意义的客户（覆盖HR、Finance、IT，未具名）

公司自己讲的数字 · 一般 · 原文写了驻场团队

Kevin Bai — Member of Technical Staff，Anthropic

Kevin Bai 个人页。2025–2026 任 Rippling 创始驻场工程师 / Manager，旧金山湾区。页上写：Rippling 的第一位 FDE hire。帮忙把 FDE 职能立起来——一部分咨询、一部分产品经理、一部分软件工程师：founder-shaped 的工程师——并通过面试和招聘把团队带大。为 Rippling 最大、最具战略意义的客户解企业题，覆盖 HR、Finance、IT。北星是客户在 Rippling 上的成功：「如果客户需要的 SKU Rippling 没有，我们就发明它。」创建了 Slack 频道和 GitHub 仓库，写了第一批 FDE SOP，写了首批 250K 行 FDE 代码，然后做了 Rippling 的 MCP server 和 10+ Skills，用来倍增 FDE 产出和开发者体验。同一页 CPG 800 用户 / 航空公司每周 10 小时属于其他 Selected work 条。

给负责人

要解决什么
大客户需要的 SKU，Rippling 当时并不存在——产品缺口直接卡住最大战略客户的成功。
结果
作者作为首名 FDE 从 0 搭建 FDE 职能，团队随后增长至 20+ 人；编写了首批 25 万行 FDE 代码；建成 Rippling 的 MCP server 与 10+ Skills 用于倍增 FDE 产出与开发者体验。
驻场怎么写的
Founding Forward Deployed Engineer / Manager：顾问 + 产品经理 + 软件工程师的「创始人型工程师」；负责为客户解决企业问题，并通过面试与招聘把团队扩大；技术栈为 TypeScript、React、Python。

给现场的人

主要用在哪
客户需要而 Rippling 没有的 SKU，FDE 现场把它造出来；为放大 FDE 产出与开发者体验，随后构建了 Rippling 的 MCP server 和 10+ 个 Skills。
怎么上线
建立了 Slack 渠道与 GitHub 仓库，并撰写了首批 FDE SOP。
能不能复用到下一家
把交付沉淀为可复用资产：Rippling MCP server + 10+ Skills，用于放大 FDE 产出与开发者体验；并撰写首批 FDE SOP，形成团队可复制的工作方式。
如果客户需要的 SKU Rippling 没有，我们就把它造出来。我们的北极星是客户在 Rippling 上的成功。

备注

作者个人网站简历页自述，含量化细节（25 万行代码、MCP server、10+ Skills、团队由 1 人增至 20+ 人），但无客户侧业务 KPI；与同作者 FDE Pod 文章中「我是 Rippling 第一个 FDE，团队已超过 20 人」的叙述一致。客户未具名。
