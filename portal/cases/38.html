Draftwise — 使用 Cohere 模型搜索质量 +30%

Draftwise 采用 Cohere 的 Command、Embed 和 Rerank 模型，为合同起草平台提供语义搜索和语言生成能力。

这些功能让用户能立即从过往协议中调出相关条款和示例，减少人工审查和常规起草时间。

自从引入 Cohere 模型后，Draftwise 的搜索结果质量提升 30%，API 调用量也大幅上升。

Overview

如果你问律师“合同起草最有成就感的部分是什么”，他们会说有机会发挥创意、给客户提供新颖的策略建议。但问他们把时间花在哪里，答案就反过来了。

“我接触的律师常自嘲是‘剪切粘贴机器人’，”Draftwise 联合创始人兼 CEO James Ding 说。Draftwise 是一款由客户法律专业知识驱动的 AI 合同起草、审查和谈判平台。

作为软件工程师，James 曾在多个注重隐私、数据安全和高级搜索能力的行业带过团队。他知道法律行业可以通过最先进的生成和搜索 AI 模型，快速起草高质量合同，减少耗时的重复工作。

为实现这一愿景，James 和 Draftwise 团队选择了通过 Microsoft Azure AI Foundry 提供的 Cohere 模型。

Challenge

Draftwise 开发团队制定了将 AI 合同起草产品 Smart Draft 推向市场的策略。

基于对 Microsoft Azure 的丰富经验和深度信任，公司创始人研究了 Azure AI Foundry 上的大语言模型，发现了 Cohere 的一系列模型：用于文本生成的 Command，以及用于搜索和检索的 Embed 和 Rerank。

“一旦知道可以在 Azure 上运行 Cohere 模型，我们就确信能兼得两者之长，”James Ding 解释道。

Draftwise 团队还直接走访潜在客户，深入了解当今律师的需求和偏好，发现客户群体对职业理念高度认同。

The Solution

起草法律协议时，律师需要从客户的合同、沟通记录和其他文件中获取具体信息。Draftwise 需要强大的检索增强生成（RAG）系统来驱动合同生成工具 Smart Draft。

Draftwise 选择了 Cohere 模型，因其质量、准确性和搜索检索能力，随后用三款强大的 Cohere 模型构建了 RAG 系统：Command、Embed 和 Rerank。

Cohere Command 模型提供强大的文本生成能力，能引用源文档，为 Smart Draft 提供自然易用的界面。

Cohere Embed 是一款多模态嵌入模型，能通过语义而非简单关键词对任何源文档进行高级搜索。Embed 可处理所有数据，包括图像、图表、表格和图形，这意味着 Draftwise 的解决方案不限于文本搜索。

最后，Cohere Rerank 确保最相关的结果排在最前面。三款模型叠加提供准确信息，并附带可验证的源文档引用，支持复杂的法律案件。

“我们为真实商业用例构建了模型，”Cohere 客户体验与合作伙伴负责人 Nicolás Morales 说。“Cohere 安全、以企业为中心的生成和检索 AI 模型能无缝融入工作流，提供强大的结果，支持广泛的多语言、高准确率引用和成本效益。”

“Cohere 将搜索质量提升 30%，让律师能随时获取正确的专有数据。”

James Ding
Draftwise 联合创始人兼 CEO

The Impact

Draftwise 的 Smart Draft 解决方案通过减少合同起草中的重复工作，让律师有更多时间做策略性客户工作。

公司通过用 Cohere 构建 RAG 驱动的 AI 搜索系统，取得了显著成果。

自从将微调后的 Cohere 模型集成到解决方案中，Draftwise 的内部基准测试显示搜索结果质量提升 30%。

在后端，Draftwise 对模型的 API 调用量在 2025 年第一季度就增长了 3 倍，表明使用量激增。

Draftwise 首席客户官 Will Seaton 对此并不意外。“我们看到法律行业对 AI 的极大热情，”他说。“除了客户体验到的生产力提升和新律师培训加速，他们还在建议客户如何利用 AI 改善运营。”
