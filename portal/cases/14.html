Vega — Claude 驱动 agentic 网络防御：调查快 44 倍、成本降 82%

大企业安全数据散在几十个工具和云环境里。

理论上能全塞进 SIEM，但规模一大就太复杂、太贵。

团队通常只吃得下能付得起的那部分，剩下的就成了盲区。

查询、检测、调查都做不全。

AI 把这个矛盾放大了。

“AI agent 能看到多少数据，就有多大用处。大多数安全架构要么太零散，要么太慢，撑不起规模化 agentic 网络防御。”

Eli Rozen，联合创始人兼 CTO

一家全球前四大银行的 Amazon VPC Flow Logs、AWS CloudTrail、Microsoft 365 遥测数据都没法看，因为塞进老 SIEM 要多花 600 万美元。

Vega 想做 agentic 网络防御：agent 检测攻击后自动分诊、调查，还能自我优化。

团队选 Claude 跑生产。

“作为 AI 原生公司，我们从第一天就用 Claude 这类顶级模型，把它的推理能力定为平台基线。”

Rozen 说，安全团队要用的推理必须过硬。

Vega 先用最强的 Claude 模型定准度，再往回压成本和速度，不丢质量。

关键在于模型范围。

“Claude 让我们在同一个模型家族里，按需调用 Haiku、Sonnet、Opus 的不同智能层级。”

最深推理给已确认告警，风险最高；日志分析、摘要这类高量活跑在轻快模型上。

“客户感受到的是规模下的速度和精准；我们自己感受到的是单位经济能控住，同时保证网络防御工程师在关键处拿到前沿答案。”

Vega 在 Anthropic 的 Agent Skills 格式上做了扩展，推出 detection skills。

这是一个开放标准，让网络防御工程师把自己的判断写成 agentic 循环：如何分诊、调查、优化一个检测。

Vega 把标准放到了 detectionskills.io，方便各平台安全团队把判断编码、分享给社区。

检测触发后，循环就按这份判断跑。

分诊技能决定告警是否升级成事件，并附上推理。

调查技能在人看之前先分析事件：提假设、搜证据、起草带解释的结论和下一步建议。

优化技能把已批准的结论写回检测，让它下次打得更准。

每处改动都由工程师签字，判断权还在人手里，重复活却在人来之前就做完了。

推理通过 Amazon Bedrock 给客户：零数据留存、不用客户数据训练、VPC 端点不走公网、透传定价。

内部工具和 Claude Code 走直连 Claude API。

用量上来后，Amazon Bedrock 的跨区推理扛住了峰值，Vega 不用自己扩容。

Vega 是全球公司，要满足各地合规、隐私、主权要求。

有客户需要 GDPR 的欧盟数据驻留，Vega 三周内在法兰克福搭起专用控制平面，跑 Amazon Bedrock 欧盟托管的 Claude 模型。

“作为 AI 原生公司，我们从第一天就用 Claude 这类顶级模型，把它的推理能力定为平台基线。”

Eli Rozen，联合创始人兼 CTO，Vega

给负责人

要解决什么
安全团队只能对负担得起摄取的数据做防御；摄取不到的数据成盲点。传统 SIEM 摄取贵（某全球前四大银行额外 600 万美元）。
结果
调查最多快 44 倍、成本降 82%（对比传统 SIEM）。某 Fortune 500：分诊 25 分钟→不到 3 分钟。回收约 67% 分析师时间。10 亿条 CloudTrail 日志 / 17 个区域 41 秒扫完（手工基线 30 分钟）。
接了哪些系统
推理经 Amazon Bedrock 触达客户（零数据保留、VPC endpoints、pass-through pricing）；直接 Claude API 用于内部工具/Claude Code；基于 Anthropic Agent Skills 格式构建 detection skills
用了什么数据
Amazon VPC Flow Logs、AWS CloudTrail、Microsoft 365 telemetry；超 1 billion CloudTrail logs 跨 17 AWS regions
人还管哪一步
工程师对每次变更签字批准；判断仍属工程师，重复工作在到达前完成
多久上线
EU residency 控制平面 under three weeks
怎么交给客户
客户经 Bedrock 自服务；Vega 工程团队+CTO 构建优化

给现场的人

主要用在哪
智能体网络防御：发现攻击后自己分诊、调查、优化整套环境；Claude 当推理引擎，驱动检测技能循环。
以前怎么干
大型企业安全数据散落在几十个工具和云上；理论上全量进 SIEM，实际只摄取负担得起的一小部分。
卡在哪
采样切片把所有盲点一起继承。SOC 只看采样数据，VPC Flow Logs / CloudTrail / M365 遥测看不见。
用了什么模型
Claude 单模型族：最深推理（确认告警）用 Opus；高容量（日志分析/总结）用 Haiku/Sonnet
事情怎么流转
Triage skills（是否升级为事件+推理）→ Investigation skills（人工介入前分析、假设、证据、可解释结论）→ Optimization skills（把批准裁决写回检测，下次更准）
怎么验收
以最强 Claude 模型设准确基线，向后优化成本效率不损质量；生产中严格测质量
怎么上线
Bedrock 跨区推理吸收负载峰值；GDPR 需求下法兰克福建专用控制平面（Bedrock EU-hosted Claude），不到三周
能不能复用到下一家
Detection Skills 基于开放 Agent Skills 标准（detectionskills.io）；Bedrock 跨区域推理
AI agent 的有效性取决于它们能访问的数据…… — Eli Rozen, Co-founder & CTO, Vega | Claude 让我们能在单一模型族内工作……覆盖 Haiku、Sonnet 和 Opus。 — Eli Rozen
