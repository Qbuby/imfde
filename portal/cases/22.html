Peek 借助 Augment Code 将测试编写时间减少 80%

Peek 选 Augment Code 前，先和几家主流 AI 工具做了三周实测。团队用使用数据、问卷和复盘来判断效果。

Peek 的平台负责体验类预订和后台运营，25 人工程团队同时维护 Ember.js、TypeScript、Elixir 和 Rails。之前用 GitHub Copilot，但效果一般。

“我们用 Copilot 一年了，没什么感觉。我们想找真正能提升效率的工具。”工程总监 Rachel Larson 说。

三款工具对比后，Augment Code 在测试自动化和重复代码生成上明显领先。

“以前写自动化测试要花 2–3 天，现在几小时就搞定。”Larson 说，“对不熟悉仓库或从零写测试的工程师帮助特别大。”

Peek 的后端有不少老 Ruby 仓库，需要对项目结构有深入理解。Augment Code 能理解代码写法，给出高质量补全。

“它不只是懂语法，还知道我们实际怎么写代码。”Larson 说。

团队不需要调模型或写复杂提示，开箱即用。

“大家只想发代码，不想研究大模型。Augment 让他们直接干活。”

标准化测试从几天缩短到几小时，测试自动化时间减少 80%。全栈工程师生成重复代码的速度提升 10 倍。新项目原型搭建也更快。

“没人会说‘我真想写 50 个一模一样的测试’。Augment 把这部分苦活拿走了。”
