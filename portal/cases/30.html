Pure Storage

公司自己讲的数字 · 比较可靠

Pure Storage 借助 Augment Code 应对复杂的 2.1M 行 C++ 代码库

Pure Storage 面对数百万行 C++ 代码库的挑战，借助 Augment 提升开发效率、加快新人上手、简化调试，团队整体生产力明显提高。

Pure Storage 是一家企业级数据存储解决方案公司，代码库庞大复杂，包含超过 2.1 百万行 C++，还有大量 Python 和 Go 代码。他们先试过 GitHub Copilot，但效果不够理想。

调试和排错是最大痛点。内存泄漏、段错误、性能瓶颈经常出现。高级软件工程师 Richard Hefner 说：“我曾把整个 React 库从一个 UI 框架换到另一个，同时还要保持能轻松拉取上游改动，这件事特别棘手。” 代码准确性也难保证，细微的数学或逻辑错误容易漏掉。

Scott Kim 工程师提到代码导航和理解的问题：“C++ 模板让每个代码库都有自己的写法，往往跟熟悉的模式差得很远。” 工程师还得处理不熟悉的技术，比如用新工具包扩展 SQL 项目，找对组件和理解测试宏都很费劲。

两支工程团队即将合并，新人必须快速上手，但面对海量 C++ 代码和各种约定，学习曲线陡峭。

Pure Storage 希望找到更智能、上下文感知更强的 AI 编程助手，最终选择了 Augment。

Augment 对 C++ 模板、内存管理、复杂类依赖的理解更深。Hefner 说：“Augment 明显比其他 AI 更聪明，通常它先给出正确答案，生成的代码质量更高。”

AI 洞察帮助工程师快速定位运行时问题、内存泄漏和逻辑错误，调试时间大幅缩短。一位开发者说：“Augment 让我轻松找到不熟悉区域的功能。后来我写了一些带很多条件的复杂查询，请它帮忙简化，结果代码更精简、更易读。”

开发者还能快速定位函数、理解依赖、浏览遗留代码。Kim 说：“Augment 特别有用，我可以问‘这个是干什么的？怎么用的？为什么这么写？’，它都能给出指向正确方向的答案。”

与 Copilot 不同，Augment 的建议更专业。一位开发者说：“在 Copilot 里，我刚输入‘// This is’，它就会补‘// This is kind of a hack, but ...’，然后对代码一摊手。Augment 不会这样，它的注释建议总是聚焦代码本身，能很好地描述功能。”

结果显示，超过 130,000 条补全被接受进代码库，77% 的聊天式建议被采纳。Hefner 说：“我一直用 Augment，因为代码质量更高，而且它还在持续进步。”

调试和导航速度明显加快。Kim 说：“Augment 直接指方向，不用再拿基础问题去问同事。”

新人上手时间从几个月缩短到几周。

给负责人

要解决什么
在 Copilot 对付不了泄漏、段错误、模板和跨领域工作的 210 万行 C++ 代码库（外加 Python/Go）里导航、调试和入职。
结果
超过 13 万次补全被接受进代码库；77% 的聊天驱动建议被落地。入职从数月→数周。210 万行 C++ 是代码库规模，不是 Augment 产出。
接了哪些系统
VS Code、JetBrains、Vim。
用了什么数据
2.1M 行 C++ 外加 Python 和 Go。
人还管哪一步
具名 Richard Hefner（Senior Software Engineer）和 Scott Kim（Software Engineer）。
多久上线
入职时间从数月减至数周。

给现场的人

主要用在哪
在不熟的领域找功能；简化复杂条件查询；对遗留代码问「是什么/怎么做/为什么」；比 Copilot 更高质量的补全（包括注释语气）。
以前怎么干
最初用 GitHub Copilot。挑战：一边接上游一边做 React UI 框架转换；SQL 工具包扩展；这仓库特有的 C++ 模板惯用法；两个工程团队即将合并。
卡在哪
内存泄漏、段错误、性能瓶颈；C++ 模板「自己的一套」；单体上的入职障碍。
用了什么模型
Augment Code（页面：Context Engine / agents / completions；除非另有注明，无单一模型名）。
事情怎么流转
补全和聊天问答；聊天驱动的建议。
怎么验收
超过 130,000 次补全被接受进入代码库；77% 的聊天驱动建议被实现。入职数月 → 数周。
怎么上线
2000+ 工程师组织（页面页头）。补全被接受进入代码库。
失败了怎么改
Copilot 不足以应对调试、导航和 C++ 深度；Copilot 的注释建议被描述为相对 Augment 不专业。
Augment 肯定比其他 AI 更聪明——它通常比其他的更早做对，并创建更高质量的代码。——Richard Hefner, Senior Software Engineer at Pure Storage
