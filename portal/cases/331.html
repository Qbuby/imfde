CLEAR 如何用 AI 提升会员待客

CLEAR 是安全身份平台，让机场旅行这类日常体验更快、更容易、更安全。无论经机场的 CLEAR Plus 还是医疗和零售里的生物识别认证，CLEAR 为数百万会员交付无摩擦、高信任互动。为匹配产品的速度和简单，CLEAR 着手创造感觉同样无缝的会员体验。会员体验 VP Adam Luebbers：「我们常说，『你就是你。』我们相信你不必掏钱包或护照来证明你是谁。我们做的一切都是让体验更快、更容易、更安全——包括会员支持。」

Sierra 之前，CLEAR 用一套限于死板、基于逻辑回复的传统支持工具。它不能推断意图、适应口吻，或规模化以满足 CLEAR 增长中的会员基础的演进需求。这在关键时刻制造摩擦——正好是团队在努力消除的那种体验。Adam：「我们以前的工具没有在用 GenAI。它缺我们真正支持会员所需的上下文和流动性——当你的品牌迷恋无摩擦体验时，那是个问题。」找新伙伴时，CLEAR 要的不只是技术供应商。他们需要理解会员优先设计和待客之重要的团队。Sierra 突出的不只是产品，还有响应性和对持续改进与创新的共享承诺。

CLEAR 在 web 和移动上推出建在 Sierra 上的 AI agent，让会员能问从机场位置和产品细节到账户管理和服务比较的一切。以前的系统里，这些信息很多在移动应用里不可用——即使在网上，在位系统也难处理细微差别。有 Sierra，体验感觉戏剧性不同。Adam：「举例，会员有时搞不清 CLEAR Plus 和 TSA PreCheck 的差别，以为他们只需要一个。有了 Sierra，我们能澄清两者其实互补。agent 解释它们怎么一起创造更快、更无摩擦的旅行体验——这对会员理解和采用是局面改变。」同样重要的是口吻。从第一天 CLEAR 就跟 Sierra 紧密合作，确保 agent 反映公司品牌声音。团队交换流程文档、过往营销沟通和现场反馈。Adam：「我对我们能多快把它剪裁到位印象很深。它现在按我们说话的方式说话——温暖、直接、会员优先。」Sierra 能自主处理数千次互动，但从未打算替换 CLEAR 会员关怀团队后面的人。如 Adam 所说，AI agent 设计成「给我们的会员关怀坐席超能力」。「Sierra 把时间还给我们。我们的支持团队现在盯更复杂、更有意义的对话。如果会员想跟人说话，那始终是选项。这是增强，不是消灭。」

上线后头几个月，CLEAR 开始看见有意义的改善。解决率上升，甚至在 Sierra 训练阶段，客户满意度分数也改善，达到平均 4.7。Adam：「我们出门就在找持平，知道会有学习曲线。但即使在早期，我们也看见实质改善。它已经超出我们的预期，我们还有很大增长空间。」影响也延伸到内部团队。Sierra 处理高量问询后，会员关怀坐席被赋能去做更有回报的工作。Adam：「团队反馈真的正面。他们更有参与感，因为他们在进行的互动更复杂、更少重复。Sierra 交接的质量出色——它给我们会员旅程的完整视图。」路线图已在进行：探索把 agent 直接嵌进入驻流；计划扩到包括语音在内的额外通道；给目前在值机时搜品牌内容库回答会员问题的机场大使，设想一套实时、Sierra 驱动的助手即时浮出剪裁信息。CEO Caryn Seidman-Becker：「在 CLEAR，我们在建一套锚定在信任、容易和待客上的安全身份平台。与 Sierra 的合作反映那份承诺——用前沿技术按规模交付无缝、以人为中心的体验。」

给负责人

要解决什么
会员支持必须像跳过身份证钱包一样少摩擦——先前基于逻辑的工具推断不了意图，也处理不好 Plus 与 TSA PreCheck 的细微差别，尤其在移动应用里。
结果
上线后头几个月，解决率上升。即使在 Sierra 训练阶段，CSAT 也改善，达到平均 4.7。团队寻求一上来就持平，并称已超出预期。页上无基线解决百分比。
接了哪些系统
Web 与移动；计划嵌入注册流程、语音，以及机场大使助手。
人还管哪一步
增强而非消灭；如果会员想跟人谈，那始终是选项。
怎么交给客户
Adam Luebbers，会员体验副总裁；Caryn Seidman Becker，首席执行官。

给现场的人

主要用在哪
网页 + 移动会员智能体：机场位置、产品详情、账户管理、服务比较。
以前怎么干
传统支持工具，僵硬的基于逻辑的回复；移动应用里很多信息没有。
卡在哪
关键时刻的摩擦；现有方案处理不好细微差别。
用了什么模型
Sierra AI agent。
事情怎么流转
跨位置/产品/账户的会员问题；始终可选择与人交谈；带旅程上下文的高质量交接。
怎么验收
解决率（方向性上升）；即使在训练阶段 CSAT 平均 4.7。
怎么上线
Web 与移动已上线；下一步是语音与注册。
能不能复用到下一家
注册流程 agent、语音、机场大使实时助手。
