OpenAI · 制造工业

匿名客户（制造业）

公司自己讲的数字 · 一般 · 原文写了驻场团队

OpenAI Frontier

OpenAI Frontier 产品页：在单一企业平台上运转 AI 同事。接到记录系统，企业级安全治理，并设计成智能体做真实工作后随经验改进。Create competence：Business Context 连接数仓、CRM 和内部应用，让智能体能用跟人一样的信息，随时间建持久机构记忆。Run agents in production：Agent Execution 让智能体把模型智力用到真实业务情景，并行完成复杂任务。Improve with experience：内置评测和优化环。Embed trust：综合控制与审计、显式权限、可审计动作。

生产用例条里，制造业：模拟制造和产能选址，优化 $1B+ CapEx。这是本案例对应句。能源防灾、生命科学监管、银行数亿事件、通信呼叫中心，属于同页其他行业条。Enterprise Frontier Program 把 OpenAI Deployment Company 的驻场工程师跟客户团队配在一起，设计架构、把治理运转起来、在生产里跑智能体。平台写符合 SOC 2 Type II、ISO/IEC 27001、27017、27018、27701 和 CSA STAR。

给负责人

要解决什么
制造与产能选址（capacity siting）决策涉及大额资本开支，需要优化
结果
优化 10 亿美元以上的资本开支（optimize $1B+ in CapEx）
驻场怎么写的
Enterprise Frontier Program 把来自 The OpenAI Deployment Company 的前线部署工程师与你的团队配对，共同设计架构、把治理落地，并在生产中运行智能体。

给现场的人

主要用在哪
用模拟（simulating）优化制造安排与产能选址
用模拟优化制造与产能选址，覆盖 $1B+ 的资本开支。
