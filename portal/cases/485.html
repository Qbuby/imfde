什么是 Forward Deployed Engineers，为什么他们这么抢手？

Deepdives。什么是 Forward Deployed Engineers，为什么他们这么抢手？创业公司和成长型公司正在狂招一个由 Palantir 开创的软件工程岗位。这篇深挖这个角色，以及为什么 FDE 在 2025 年这么火。Gergely Orosz，2025 年 8 月 12 日 ∙ 付费。今年 AI 创业赛道一个有意思的趋势，是一个叫「Forward Deployed Engineer」（FDE）的专门软件工程岗位走到台前。这个角色甚至被风投机构 a16z 叫做「科技最热岗位」。FDE 混着软件、销售和平台工程，大约从年初开始招聘明显抬头，燃料是接入 AI 方案的需求。可招这个岗的不只是 AI 创业公司。

给负责人

要解决什么
呼叫中心自动化场景：语音模型表现不足以让客户承诺部署
结果
客户成为第一个在生产环境部署该进阶方案的客户；OpenAI 的 Realtime API 也因这项工作得到改进，成果惠及所有客户
驻场怎么写的
FDE 比解决方案架构师（SA）更动手：直接在客户基础设施上用客户工具写代码，处理更高模糊度，并与 OpenAI 的研究目标对齐

给现场的人

主要用在哪
呼叫中心自动化的语音 agent
卡在哪
模型质量不达标导致客户不愿上生产
用了什么模型
语音模型（OpenAI Realtime 相关能力）
怎么验收
FDE 为该语音模型构建 evals；初期模型表现不达标，FDE 带着数据回到 OpenAI 研究部门改进语音场景下的模型表现，再进行 eval 驱动的迭代
怎么上线
客户成为首个在生产环境部署该进阶方案的客户
失败了怎么改
首次部署尝试因模型表现不足未获客户承诺 → FDE 携数据回研究部门改进模型 → 客户首个上生产
能不能复用到下一家
FDE 的现场工作直接改进了模型与 Realtime API，形成对所有客户可用的产品能力
FDE 团队带着数据回到 OpenAI 研究部门，改进语音场景下的模型表现，最终让该客户成为第一个在生产环境部署该进阶方案的客户。

备注

由 OpenAI FDE 负责人 Colin Jarvis 口述的二手叙述；客户未具名、无量化指标，但因果链（eval → 回研究部门 → 模型改进 → 首个生产部署 → Realtime API 受益）具体
