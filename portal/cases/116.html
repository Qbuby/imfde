GCash 如何用 Glean 为 100 million 用户提升金融安全

GCash 是菲律宾领先的金融应用。20 多年来，GCash 致力于数字普惠金融，帮助近 100 million 用户安全管理财务、实现全球金融安全。

在引入 Glean 之前，GCash 面临信息查找难题。没有统一的内网，员工只能手动翻找，速度跟不上业务节奏。

员工还要在多个应用间反复切换，容易打断工作状态，影响专注和效率。他们需要一个集中、可搜索的内网，把散落在各应用里的数据整合起来，并提供日常工作的上下文。

Glean 提供了统一视图，把所有知识源串联在一起。

合规团队尤其受益。他们现在能索引并随时掌握多家监管机构制定的敏感合规标准。

过去，员工经常打断自己或同事的工作去问信息。这种方式既低效，又损害整体生产力。

现在，Glean 把企业信息集中索引，员工能即时搜索到所需内容，全天保持信息通畅和专注。

Glean 还让 GCash 把公民开发者计划扩展到 AI 领域。员工可以用自然语言，通过 Glean Agent Builder 自己搭建应用。

GCash 各团队正把定制化代理逐步融入日常流程。

“五到十年后，工作方式将彻底改变——我们所有团队都会有自己的 Glean AI 代理协助工作。”

Benson Tan
GCash 自动化解决方案高级经理

目前，Glean 每周为 GCash 员工节省 2-3 小时，带动口碑传播，部分部门采用率超过 90%。

接下来，GCash 计划扩大 Glean 使用范围，例如缩短 IT 支持工单处理时间。

GCash 希望为每个业务单元至少打造一个定制 AI 代理，自动化行政工作，让员工专注于需要判断的高价值任务，保持竞争优势。

给负责人

要解决什么
建立可集中搜索的内网，让员工不再在应用间切换、互相打断去要信息，尤其是要跟踪众多监管机构的合规团队。
结果
每名员工每周节省 2–3 小时。部分部门采用率超过 90%。口碑强。「每个业务单元至少一个智能体」和 IT 工单 TAT 是目标，不是结果。100 million 用户是 GCash 规模。
接了哪些系统
Agent Builder 延伸现有公民开发者项目。未点名 ITSM/CRM。
用了什么数据
许多未点名的数据源 / 应用。来自多个监管机构的合规标准。
人还管哪一步
公民开发者。口碑支持。行政工作自动化后，基于判断的工作仍由人完成（方向性）。
多久上线
未标注日期。

给现场的人

主要用在哪
统一企业索引（合规是突出使用者）。面向公民开发者的 Agent Builder。未来：IT 支持工单周转——计划中。
以前怎么干
没有集中内网。手动、跨多应用发现。人们打断他人工作流去询问信息。已有公民开发者项目，并通过 Agent Builder 延伸到 AI。
卡在哪
可发现性跟不上增长。上下文切换打断专注。合规需要监管标准的实时索引。
用了什么模型
Glean 搜索 + Agent Builder（自然语言）。未给出基础模型名称。
事情怎么流转
团队用自然语言构建个性化业务智能体并接入工作流。目标：每个业务单元至少一个定制 AI 智能体（目标，不是计数）。
怎么验收
Glean 为 GCash 员工每周节省 2–3 小时。部分部门采用率超过 90%。100 million 是 GCash 的用户基数，不是 Glean 成果。IT 工单 TAT 是下一步。
怎么上线
部分部门采用率超过 90%。计划扩展到更多项目。
能不能复用到下一家
扩展到 IT 支持工单；每个业务单元一个定制智能体——表述为目标。
五到十年后，我们的工作方式将彻底改变——所有团队都会有自己的 Glean AI 智能体来协助。——Benson Tan，自动化解决方案高级经理，GCash
