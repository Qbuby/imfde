Substack — Decagon 自动解决 90%+ 用户询问，并驱动产品洞察

Substack 让任何人创建集个人网站、博客、邮件通讯或播客于一体的出版物。自 2017 年起，Substack 的订阅网络已增长到超过 3500 万活跃订阅和超过 300 万付费订阅。随着读者和创作者不断加入，Substack 在审慎管理高量支持请求的同时，也在控制支持团队的规模。

最初，Substack 团队自建了一个聊天机器人来处理客户对话。他们很快发现，只管理回复还不够，需要一个更完整的 AI Agent 来解决以下问题：

高支持量：支持团队经常处理重复的 Tier 1 请求，例如取消订阅和导入邮件。每个对话都由人工手动处理，难以在保持高质量的同时及时回复所有询问。

缺乏分层：为了提供针对性支持，Substack 需要标签和路由系统，以便更好地理解并满足不同群体的需求——无论是出版者、订阅者，还是免费或付费层级。

洞察有限：自建方案只关注回复管理，没有提供用户分析或趋势洞察，难以全面了解客户声音并发现 CX 运营的改进空间。

扩展挑战：除了现有支持量，团队还想主动联系部分出版者，帮助他们发展出版物。这种主动方式会增加支持量，因此需要 AI Agent 能应对额外涌入的客户互动。

Substack 与 Decagon 合作，推出了：

AI 驱动的聊天机器人：Decagon 部署的 AI Agent 可处理并解决超过 90% 的用户询问，大幅减轻现有支持团队负担。

自定义分层过滤器：Decagon 添加标签和自定义过滤器，帮助 Substack 为社区提供针对性、情境化支持（例如向高收入作者提供变现建议，促成免费订阅者付费）。

客户声音洞察：通过对历史对话打标签，Substack 能了解出版者和订阅者最大的痛点，追踪联系驱动因素，填补产品或文档空白，并升级功能请求。

工作流集成：跟踪功能请求和报告 bug 曾是手动流程，Decagon 现可通过直接集成 Substack 现有的客户支持工具，自动识别、跟踪并报告功能请求和 bug。

Substack 能取得世界级解决率和 CSAT，很大程度上归功于 AI Agent 执行操作并处理常见但复杂、多步骤询问的能力。以退款和取消为例，通过将 AI Agent 连接到正确 API 并教会它人类代理的逻辑，AI 能端到端处理整个问题。这不仅能自动处理更多案例，还能为终端用户创造神奇体验。当客户能立即得到所需内容时，团队观察到 CSAT 出现阶跃式提升。

Decagon 的 AI Agent 提供客户声音洞察、对用户分层并深入客户趋势，为 Substack 团队带来一致成果：

支持能力提升：Substack 在不增加团队规模的情况下，以快速准确的方式扩展了解决支持量的能力。

客户满意度提高：Decagon 的 AI Agent 帮助 Substack 在无需人工干预的情况下成功解决超过 90% 的用户问题，带来持续高 CSAT 和偏转率，以及更短的解决时间。

高价值用户专用资源：有了 Decagon，支持团队现在能投入更多时间帮助顶级作者和创作者解决增长、营销和产品相关询问，从而增加整体收入。
